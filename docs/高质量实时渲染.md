## 一、软阴影

### 1. 硬阴影和软阴影有什么区别？软阴影怎么实现？

**答案：**

硬阴影的边缘从亮到暗直接跳变；软阴影具有半影区，因为面积光源在这些位置只被部分遮挡。接收点越靠近遮挡物，阴影通常越硬；光源越大，半影通常越宽。

常用实现：

- **PCF**：对 Shadow Map 多次深度比较并平均结果，得到柔化边缘。
- **PCSS**：先找遮挡物，再估计半影宽度，最后按该宽度做 PCF，模拟接触硬化。
- **VSM／VSSM／MSM**：保存深度统计矩，利用可过滤的数据估计可见性。
- **SDF**：沿光源方向对距离场步进，估计遮挡与半影。
- **光线追踪**：在面光源上采样多个位置，发射阴影射线，按可见样本累加光照；低样本时配合降噪。

固定核 PCF 主要是柔化硬边；PCSS 和面积光源采样更能体现半影随距离变化。

### 2. PCF 的原理和实现步骤是什么？

**答案：**

PCF（Percentage-Closer Filtering）过滤的是**深度比较结果**。

1. 把接收点变换到光源空间，得到 Shadow Map UV 和比较深度。
2. 在 UV 邻域取多个样本，每个样本分别判断接收点是否可见。
3. 对可见性加权平均，作为该点的光照可见系数。

例如 9 个样本中 6 个可见，系数为 6/9。优点是简单、适合硬件比较采样；缺点是大核采样贵，固定核不能正确反映接触硬化。不能先平均深度再只比较一次。

### 3. PCSS 的原理和实现步骤是什么？

**答案：**

PCSS 用接收点与遮挡物的距离估计半影大小，流程分三步：

1. **遮挡搜索**：在 Shadow Map 中找比接收点更靠近光源的样本，求平均遮挡深度 dB。
2. **半影估计**：典型近似为 `wPenumbra = wLight × (dR−dB)/dB`，dR 为接收点距离。
3. **可变核 PCF**：半影越宽，使用越大的过滤范围。

距离使用与公式相符的线性光源空间距离，再换算成纹理核宽。PCSS 能表现“接触处硬、远离后软”，代价是遮挡搜索和多次过滤，复杂遮挡层次可能出现噪声或漏光。

### 4. VSM 和 VSSM 的原理是什么？为什么会漏光？

**答案：**

VSM 保存深度一阶矩 `E[z]` 和二阶矩 `E[z²]`。过滤后得到均值 μ 和方差 `σ²=E[z²]−μ²`，再用统计界近似可见性。对接收深度 t>μ：

```text
可见性上界 ≈ σ² / (σ² + (t−μ)²)
```

矩可以先过滤，因此大范围过滤比逐样本 PCF 更方便。VSSM 在此基础上进一步近似遮挡搜索和可变半影。

漏光来自有限统计量无法还原完整深度分布：多个遮挡层可能具有相近均值／方差，估计结果把实际被挡住的区域判得过亮。

### 5. SAT 和 MSM 在阴影中有什么作用？

**答案：**

SAT 是求和面积表，用四次前缀查询得到轴对齐矩形范围的和，适合计算大范围深度矩；代价是构建和存储，以及大数相减的精度问题。

MSM（Moment Shadow Mapping）常保存前四阶矩，比只用均值／方差更好地估计可见性，通常能减少漏光，但存储和求解成本更高。它仍是近似，不会完整恢复所有遮挡层。

### 6. SDF 软阴影怎么实现？

**答案：**

从着色点沿光源方向步进。距离场给出当前位置到表面的距离，可用它决定下一步走多远；若接近表面则判遮挡。

软阴影常在步进中累积 `min(k × distance / rayDistance)` 一类近似，表示射线与周围遮挡物的接近程度。优点是可复用场景距离场、半影自然；缺点是距离场存储和更新成本，以及薄物体、低分辨率造成的漏光。近似 SDF 需要保守步长。

### 7. CSM 的原理是什么？如何减少级联切换和阴影抖动？

**答案：**

CSM 将相机视锥按深度分段，每段从方向光视角生成一张 Shadow Map，让近处获得更高阴影密度。

实现时确定分段范围，计算各段光源投影，渲染阴影，再按接收点深度选择级联。级联重叠区做混合可减少接缝；稳定投影和按阴影纹素对齐可减少相机移动造成的抖动。代价是多次阴影绘制和额外存储。

### 8. 点光源阴影怎么实现？

**答案：**

常用 **Cubemap 阴影**：从点光源向六个方向渲染深度，着色时用“光源到接收点”的方向选择面并比较相同定义的深度。优点是覆盖完整空间；代价是最多六个视图的绘制和存储。

也可用双抛物面映射覆盖两个半球，减少视图数量，但非线性投影、半球接缝和三角形变形处理更复杂。

## 二、环境光与预计算

### 9. 什么是 IBL？漫反射和镜面 IBL 如何实现？

**答案：**

IBL 用环境图表示来自各方向的光，为物体提供环境照明和反射。

- **漫反射**：对环境光做余弦加权积分，预计算为辐照度图，或投影到低阶球谐系数；运行时按法线查询。
- **镜面反射**：预生成不同粗糙度的环境图，运行时按反射方向和粗糙度采样，再结合 BRDF 积分表。

优点是用少量查询得到丰富环境光；缺点是环境图通常假设光来自远处，局部视差、动态物体和遮挡需要探针、AO 或其他方法补充。

### 10. Split-Sum IBL 的原理是什么？

**答案：**

把镜面环境积分近似拆成两份预计算数据：

1. **预过滤环境图**：按粗糙度生成不同宽度的反射波瓣积分，通常存成不同 mip。
2. **BRDF LUT**：按 N·V 和 roughness 保存 Fresnel 分解后的 scale、bias。

```text
specularIBL ≈ prefilteredEnvironment(R, roughness)
              × (F0 × LUT.r + LUT.g)
```

运行时只需少量贴图查询。预过滤核和 LUT 必须匹配所用 BRDF；掠射角和强高频光源下会出现分解误差。

### 11. 球谐函数是什么？为什么常用来表示漫反射环境光？

**答案：**

球谐函数是一组球面正交基，可以用少量系数近似方向分布。

```text
投影：ci = ∫ f(ω) Yi(ω) dω
重建：f(ω) ≈ Σ ci Yi(ω)
```

漫反射积分会平滑环境中的高频变化，所以通常用到 l=2 的 9 项就能取得较好的效果，RGB 各存一组。优点是存储少、求值快、便于旋转；缺点是无法表现锐利高光或硬阴影。

### 12. PRT 的原理和优缺点是什么？

**答案：**

PRT 是预计算辐射传输：提前计算表面各点对不同入射方向的传输响应，把可见性、余弦项及可选互反射投影到基函数。

运行时把当前环境光投影到相同基，漫反射情形通常通过光照系数与传输系数点积得到结果。光照可改变，而主要计算已提前完成。

优点是运行时很快，还能包含自遮挡和多次反弹；缺点是数据和预处理成本较大，几何／材质改变会使原传输数据失效，低阶基也难表达高频效果。

### 13. Lightmap、光照探针和反射探针有什么区别？

**答案：**

Lightmap 将静态表面的光照保存到纹理，按表面 UV 采样；光照探针在空间位置保存照明信息，通过插值给动态物体提供间接光；反射探针保存局部环境图，主要近似镜面反射。

Lightmap 适合高质量静态照明，但需要 UV 和纹理存储；光照探针覆盖动态对象，但薄墙附近容易插值漏光；反射探针采样便宜，但有视差误差，动态更新需额外绘制。

## 三、实时全局光照

### 14. 什么是全局光照？直接光和间接光有什么区别？

**答案：**

直接光从光源直接到达当前表面；间接光先在其他表面散射，再到达当前表面。全局光照同时考虑这些贡献，可表现颜色渗出、阴影区域受光和多次反弹。

常见实现有 Lightmap、探针、RSM、LPV、体素锥追踪、屏幕空间 GI 和光线追踪。它们在动态性、空间覆盖、精度和实时成本之间取舍。

### 15. RSM 的原理和实现步骤是什么？

**答案：**

RSM（Reflective Shadow Maps）把直接受光的表面当作二次光源。

1. 从光源渲染深度、法线、位置或可重建位置的数据，以及反射通量。
2. 将这些纹素看作虚拟光源。
3. 在接收点对虚拟光源采样，结合距离、余弦和采样权重累加间接光。

能复用阴影视图，适合近似一次漫反射反弹；光源视图看不到的表面无法参与，不检查次级可见性时还会穿墙漏光。

### 16. LPV 的原理和优缺点是什么？

**答案：**

LPV 把场景划为三维网格，每格用低阶球谐保存方向性光照。

流程：用 RSM 等生成受光样本 → 注入网格 → 向相邻网格迭代传播 → 着色时查询并插值。

它适合较低频的动态间接光，主要成本由网格和迭代数决定。缺点是格子分辨率有限，薄墙和小物体容易漏光，低阶球谐无法表现尖锐镜面反射。

### 17. 体素锥追踪如何实现全局光照？

**答案：**

先把几何、占据率和辐射信息写入体素，构建多尺度层级；着色时从表面发射锥体，沿途根据锥的截面宽度选择 mip／层级并累积光照。

漫反射使用多条宽锥，高光沿反射方向使用较窄锥。优点是利用三维信息，可覆盖屏幕外物体；缺点是显存与动态体素化成本高，粗体素会造成漏光和模糊。

### 18. SSAO 怎么实现？HBAO 和 GTAO 有什么改进？

**答案：**

SSAO 用屏幕深度估计近邻遮挡，使缝隙、角落和接触面更暗。

1. 从深度重建位置，获取法线。
2. 在法线半球／邻域采样，投影回屏幕比较深度。
3. 统计遮挡程度，再用深度和法线引导滤波。

HBAO 用周围方向的地平线角估计遮挡，GTAO 改进对应 AO 积分的近似。共同局限是屏幕外信息缺失和薄面／深度不连续伪影。AO 表示遮蔽，不直接生成彩色反弹光。

### 19. SSDO／SSGI 怎么实现颜色渗出？

**答案：**

从着色点采样方向，在屏幕深度中寻找相交表面；读取命中位置的颜色和光照，把它作为二次光源估计间接光。方向性光照使结果不仅是灰色遮蔽，还能产生颜色反弹。

常配合低分辨率、随机采样、时间累积和保边滤波。局限是看不到离屏或被遮住的表面，需要探针／环境回退；读取已含间接光的颜色时要避免重复反馈。

### 20. SSR 的原理和优化方法是什么？

**答案：**

SSR 利用屏幕深度和颜色近似反射。

1. 由视线和法线求反射方向。
2. 沿反射射线步进，将位置投影到屏幕与深度比较。
3. 命中后读取该位置颜色，结合材质反射率与置信度合成。

可用 Hi-Z 跳过空区域、细化交点、降低分辨率并进行时间重建。优点是复用现有图像；缺点是无法反射离屏与隐藏表面，通常与反射探针或场景光追组合。

## 四、光追降噪与渲染方案

### 21. 实时光线追踪为什么有噪声？怎样降噪？

**答案：**

低采样数下，各像素随机路径贡献差异很大，形成蒙特卡洛噪声。增加采样可降低方差，但实时预算有限，通常结合：

1. 更好的重要性采样和光源采样，减少无效路径。
2. 用运动矢量重投影历史，积累多帧信息。
3. 用深度、法线、材质引导空间滤波，避免跨物体糊色。
4. 对遮挡显露、反射变化等区域降低历史权重。

降噪在噪声、模糊和拖影间取舍，不能把缺失的细节保证无损恢复。

### 22. 时间累积和重投影如何实现？如何减少拖影？

**答案：**

根据当前像素对应表面的上一帧位置，找到历史颜色，再加权混合：`C = α×当前帧 + (1−α)×历史帧`。

运动矢量需要覆盖相机和对象运动。用深度、法线、对象标识和屏幕范围检查历史是否有效；显露的新区域丢弃历史，运动／光照变化大的区域提高当前帧权重，并对历史颜色做邻域钳制。

降低历史权重会提高响应速度但增加噪声；阴影和反射运动可能不跟随表面，需专门处理。

### 23. 双边滤波、à-trous 和 SVGF 的作用是什么？

**答案：**

双边滤波同时考虑空间距离和信号差异；联合双边用深度／法线等辅助信息保边。à-trous 用间隔逐步增大的小核进行多尺度过滤，较低成本覆盖大范围。

SVGF 将历史累积、亮度方差估计和多尺度保边滤波结合，让噪声大的区域受到更强过滤。ReLAX 等降噪器也依赖相应运动、材质和命中信息；具体输入应与所用实现匹配。

### 24. Forward、Deferred、Tiled 和 Clustered Shading 有什么区别？

**答案：**

Forward 绘制物体时计算光照；Deferred 先写 G-buffer，再对可见表面计算光照，适合多灯但增加附件带宽，透明通常另走 Forward。

Tiled 按屏幕块筛选影响该块的灯，Clustered 再加入深度分层，使每个像素只遍历相关光源。二者可配合 Forward 或 Deferred，而不是另一个互斥的基本流程。选择看光源数量、透明、MSAA 和带宽预算。

### 25. 时间超分辨率和 TAA 有什么关系？

**答案：**

TAA 用抖动采样和历史重投影减少锯齿；时间超分进一步利用低分辨率当前帧和历史信息重建高分辨率图像。

二者都需要正确的运动矢量、历史拒绝和曝光处理。透明、细线、遮挡显露是难点。帧生成预测中间帧，与提升当前帧分辨率是不同任务。

### 26. 实时 GI 为什么常采用混合方案？

**答案：**

屏幕空间方法便宜，但缺离屏信息；三维探针／缓存覆盖广，但细节和更新受限；光追能测试场景几何，但成本高。因此常先用屏幕信息，失效处再查探针、距离场或光追。

Lumen 等系统就是这种组合思路的实例。工程重点是回退区域的遮挡、亮度和时间稳定性，而不只是把几个效果相加。
