## 建议复习顺序

1. C# 基础与集合，以及 Unity 性能定位、帧时间、GC 和内存分析。
2. 资源所有权、加载流程、渲染与 UI 热点，结合实际问题做对照验证。
3. 编辑器资源检查、日志分析和自动化工具，完成一个可展示的小范围交付。
4. 穿插复杂度、排序、哈希、队列和图遍历；再补 Lua、必要网络基础与英文文档阅读。

具体范围、时间分配、实践产出及面试自查见 [岗位学习路线](Unity性能与工具开发岗位学习路线.md)。

## 本次材料的归档方式

- Unity 长题单中的 C#、算法、网络与图形学题已归入对应专题；重复问题补充现有答案。
- 资源管理文章整理为 Unity 的资源系统、导入、meta、项目目录、迁移、加载方式与 Bundle 分组问答。
- 社招笔记中的 A*、消除、射线求交、Lua、HTTP/TCP 等补齐答案；UI 和动画实践仍留在 Unity。
- 旧 UnityScript／Boo、NGUI、固定功能 Shader 等保留为带历史语境的题目，不作为现代默认选型。

## 易错点提示

- 区分托管分配与真正发生回收、资源纳入包体与运行时入内存。
- 区分直线、射线和线段的参数范围，平行、共线和零方向要单独处理。
- 区分连通块消除与横竖线三消，不直接复用不匹配的搜索规则。
- Lua GC 与排序实现应标明版本；HTTP 方法语义不等于传输加密。
