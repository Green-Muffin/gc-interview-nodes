## 建议复习顺序

1. 语言基础：C++／C# 的类型、对象生命周期、资源管理、集合与并发；按需对照 Lua。
2. 数据结构与算法：复杂度、排序查找、链表与树、堆与哈希、图遍历及算法思想。
3. 图形学：数学变换、管线、采样、光照，再连接 API、Shader 与高级渲染。
4. 工程系统：Unity 资源、UI、动画、网络与工具；结合性能测量解释各项取舍。
5. 遇到具体实现再深入扩展与平台细节；优先能说明原理、前提和典型失败案例。

特定目标的时间分配与实践安排可单独参考[岗位学习路线](Unity性能与工具开发岗位学习路线.md)，不作为本题库收录内容的筛选条件。

## 易错点提示

- 区分托管分配与真正发生回收、资源纳入包体与运行时入内存。
- 区分直线、射线和线段的参数范围，平行、共线和零方向要单独处理。
- 区分连通块消除与横竖线三消，不直接复用不匹配的搜索规则。
- Lua GC 与排序实现应标明版本；HTTP 方法语义不等于传输加密。
- C++ 的语言保证与 ABI 实现细节分开记忆；区分移动转换与真正移动、迭代器与元素引用、无锁算法与原子自旋锁。
- 图形学中区分反射积分与自发光、RR 存活概率与终止概率、方向 PDF 与面积 PDF；延迟渲染并非绝对不能用 MSAA，Tile 驻留与异步队列重叠也不是 API 无条件保证。
