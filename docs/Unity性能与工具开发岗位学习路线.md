# 面试复习安排

本页是复习辅助，不参与题库选题或题数统计。具体题目从[总目录](面试题库总目录.md)进入。

## 怎么使用题库

1. 先看题目，尝试独立回答，再对照答案补缺。
2. 概念题说清定义和用途；算法题说清原理、步骤及优缺点；代码题写出核心实现。
3. 将答不出的题记录到自己的复习清单，下一轮只复习薄弱项。
4. 遇到具体版本、设备或实现差异，再查相关资料，不必把所有边界都塞进第一次回答。

## 模块顺序

| 模块 | 先掌握 |
| --- | --- |
| C++／C#／Lua | 类型、对象生命周期、资源管理、集合、并发 |
| 数据结构与算法 | 排序查找、链表与树、堆与哈希、图搜索、典型手写题 |
| 图形学 | 变换、管线、采样、光照与阴影，再学光追和实时近似 |
| API／Shader | 对象与绑定、阶段数据、空间变换、纹理和 Compute |
| Unity | 生命周期、物理／UI、资源加载、渲染、GC、动画与系统设计 |
| 工程实践 | 复现问题、采样定位、实现工具、对照复测 |

按已有基础选择起点，不以某个岗位作为其他知识的删选条件。

## 项目题准备

选一个实际做过的加载、渲染、UI、内存或工具案例，准备：问题表现、定位过程、关键实现、前后数据、代价和后续改进。先练两三分钟完整说明，再练代码和细节追问。
