## 一、渲染管线与空间变换

### 1. 光栅化渲染管线有哪些阶段？

**答案：**

应用准备数据与绘制命令 → 顶点处理 → 图元装配与裁剪 → 透视除法和视口变换 → 光栅化 → 片元着色 → 深度／模板／混合 → 帧缓冲。

顶点阶段变换位置并输出属性；光栅化确定图元覆盖哪些采样点并插值属性；片元阶段计算颜色。硬件可在条件允许时提前做深度测试，以跳过被遮挡的着色工作。

### 2. 顶点着色器和片元着色器分别做什么？

**答案：**

顶点着色器读取位置、法线、UV 等顶点属性，完成变换、蒙皮等工作，输出裁剪位置和待插值数据。

片元着色器读取光栅化后的属性，进行纹理采样、光照和材质计算，输出颜色等结果。顶点工作主要随几何量变化，片元工作主要随屏幕覆盖和重复覆盖变化。

### 3. Pixel、Sample 和 Fragment 有什么区别？

**答案：**

Pixel 是图像上的像素位置；Sample 是覆盖和深度等操作使用的采样位置；Fragment 是图元光栅化产生的候选片段。

同一像素可被多个图元覆盖，产生多个片段，最终由测试和混合决定结果。MSAA 下一个像素有多个样本，但不必为每个样本都完整执行一次着色。

### 4. 模型空间到屏幕空间怎样转换？

**答案：**

采用列向量时，先用模型矩阵 M 从模型到世界，再用视图矩阵 V 到相机空间，最后用投影矩阵 P 得到裁剪坐标：`clip=P×V×M×position`。

裁剪后执行 `ndc=clip.xyz/clip.w`，再用视口变换映射到屏幕。位置通常 w=1，方向 w=0；不同 API 的深度范围和屏幕 Y 约定要对应处理。

### 5. View Matrix 怎么求？

**答案：**

View Matrix 是相机世界变换的逆，用于把世界中的物体转换到相机坐标系。

相机刚体变换含旋转 R 和位置 t 时，视图旋转为 `Rᵀ`，平移为 `−Rᵀt`。也可通过相机的前、右、上方向构造正交基，再处理相机位置。相机朝 +Z 或 −Z 取决于坐标约定。

### 6. 正交投影和透视投影有什么区别？

**答案：**

正交投影不产生近大远小，平行线仍平行，常用于 UI、工程视图和部分方向光阴影。

透视投影模拟相机，远处物体投影更小。投影矩阵生成齐次坐标，随后除以 w 实现透视缩放。对称视锥有 `top=near×tan(fovY/2)`、`right=top×aspect`。

### 7. NDC 是什么？为什么要先裁剪再除以 w？

**答案：**

NDC 是归一化设备坐标，由裁剪坐标除以 w 得到。常见 x、y 范围为 [-1,1]；默认 OpenGL 的 z 范围为 [-1,1]，Vulkan／Direct3D 常用 [0,1]。

先在齐次空间裁剪，可正确处理跨视锥边界或相机附近的图元，避免直接除以接近零或负的 w 导致错误投影。裁剪可能生成新顶点，并插值其属性。

## 二、光栅化与可见性

### 8. 三角形如何进行覆盖测试和属性插值？

**答案：**

用三条边的边函数判断采样点是否位于三角形内，通常只检查三角形屏幕包围盒中的区域；共享边采用一致规则，避免重复覆盖或裂缝。

重心坐标满足 `λ0+λ1+λ2=1`。透视投影后的 UV 等属性通常按下式校正：

```text
a = (λ0 a0/w0 + λ1 a1/w1 + λ2 a2/w2)
    / (λ0/w0 + λ1/w1 + λ2/w2)
```

法线插值后通常还要归一化。

### 9. 视锥剔除、背面剔除、遮挡剔除和裁剪有什么区别？

**答案：**

- **视锥剔除**：剔除完全处于相机视锥外的对象或包围体。
- **背面剔除**：按投影后的顶点绕序剔除背面图元。
- **遮挡剔除**：剔除被其他物体完全挡住的对象，常用 Hi-Z 或遮挡查询。
- **裁剪**：切掉图元超出裁剪体的部分，保留里面的部分。

前三者主要决定整块不画，裁剪会改变图元边界。小于一个像素的三角形仍可能覆盖采样点，不能一律剔除。

### 10. 深度测试和模板测试的作用是什么？

**答案：**

深度测试比较当前片段与深度缓冲，确定遮挡关系；深度写入决定是否更新缓冲，两者是独立状态。

模板测试对整数模板值按规则比较，并在不同测试结果下更新模板缓冲，常用于遮罩、Portal、描边和阴影体。两种测试可配合，让只有指定区域且深度通过的片段写入颜色。

### 11. 什么是 Early-Z？什么情况下效果会受限制？

**答案：**

Early-Z 在片元着色前先检查深度，让已被遮挡的片段跳过昂贵着色。

写自定义深度、discard 或其他副作用可能限制提前测试／更新的方式，但不等于所有早期剔除都完全关闭。透明物体不写深度时，仍可利用已有不透明深度排除隐藏片段。深度预通道可增强剔除，也会增加一次几何工作。

### 12. Alpha Test 和 Alpha Blend 有什么区别？

**答案：**

Alpha Test／Clip 按阈值丢弃片段，适合树叶、铁丝网等镂空；Alpha Blend 按透明度与已有颜色混合，适合玻璃、烟雾等半透明。

Clip 边缘较硬，可结合 alpha-to-coverage；Blend 通常需远到近排序，并关闭透明物体的深度写入以免遮住后续层。

### 13. 常见混合公式是什么？透明物体为什么要排序？

**答案：**

直通 alpha 常用 `Cout=Cs×αs+Cd×(1−αs)`；预乘 alpha 的源颜色已乘透明度，常用 `Cout=Cs_pre+Cd×(1−αs)`。加法混合用于发光叠加，乘法混合用于变暗或染色。

普通 alpha 混合不满足交换律，因此通常先画不透明，再按远到近画透明。相交透明物体可能无法按对象正确排序，可考虑深度剥离或加权 OIT；后者通常是近似。

### 14. 什么是 Z-fighting？怎么解决？

**答案：**

两个表面深度很接近，深度缓冲无法稳定区分，会出现明暗交替或闪烁。

可适当增大 Near、缩小不必要的深度范围，避免近共面几何，使用合适深度偏移或更高精度格式。浮点深度配合 Reversed-Z 通常可显著改善远处精度。

### 15. Reversed-Z 的原理和实现要点是什么？

**答案：**

将近处映为 1、远处映为 0，用浮点在接近零处更密的数值分布改善透视深度精度。

修改投影矩阵，清深度为 0，比较改为 Greater／GreaterEqual，并同步调整深度重建和 Hi-Z 比较方向。主要精度收益来自浮点格式；仅反转固定点深度不会产生同样提升。

## 三、抗锯齿

### 16. 什么是走样？有哪些常见抗锯齿方案？

**答案：**

采样密度不足以表达高频信号时，会产生锯齿、摩尔纹和闪烁。抗锯齿通过更多样本、预滤波或重建减轻这些问题。

| 方法 | 原理 | 主要取舍 |
| --- | --- | --- |
| SSAA | 高分辨率着色后下采样 | 质量好，像素成本高 |
| MSAA | 增加覆盖／深度采样，复用部分着色 | 擅长几何边缘，增加附件存储 |
| FXAA／SMAA | 分析图像边缘并重建 | 成本较低，可能丢细节 |
| TAA | 抖动采样并复用历史帧 | 稳定性好，需防拖影和模糊 |

### 17. SSAA 和 MSAA 有什么区别？MSAA 有哪些缺点？

**答案：**

SSAA 增加实际着色样本，再过滤成最终像素；MSAA 主要增加覆盖与深度样本，许多样本共用着色结果，因此通常更省着色成本。

MSAA 增加颜色／深度附件容量和带宽，不能充分解决纹理、高光及透明裁剪产生的混叠。延迟渲染可以使用多采样 G-buffer，但边缘处理和光照成本更高；不是绝对不支持。

### 18. TAA 怎么实现？如何减少拖影？

**答案：**

每帧对投影加入小幅抖动，产生不同采样位置；用运动矢量将历史结果对齐当前像素，检查有效性后混合。

拖影通常来自历史位置不匹配、遮挡显露、运动向量错误或历史权重过高。处理方式是完善相机／对象运动向量，用深度和法线拒绝无效历史，对颜色做邻域钳制，并在变化较大的位置提高当前帧权重。

## 四、光照与纹理

### 19. 常见光源类型有哪些？点光源为什么按距离平方衰减？

**答案：**

平行光近似远处同方向照明；点光源从一点向周围发射；聚光灯限制方向和锥角；面光源具有面积，可产生半影和有限尺寸高光。

点光源能量分布到面积 `4πr²` 的球面，所以接收面的辐照度随距离平方下降，另乘表面入射余弦。平行光的理想模型不随场景内距离衰减。

### 20. Lambert、Phong 和 Blinn–Phong 的公式是什么？

**答案：**

Lambert 漫反射：`diffuse=Kd×light×max(N·L,0)`；严格 Lambert BRDF 为 `albedo/π`。

Phong 高光：`specular=Ks×light×max(R·V,0)^p`。Blinn–Phong 用半程向量 `H=normalize(L+V)`，将高光项改为 `max(N·H,0)^p`。

N、L、V 必须在同一空间并归一化；p 越大，高光越集中。Half-Lambert 把点积映射到 [0,1] 提亮背光，是艺术化处理。

### 21. Flat、Gouraud 和 Phong Shading 有什么区别？

**答案：**

Flat 使用面级属性，面片感明显；Gouraud 在顶点计算光照，再插值颜色，可能漏掉三角形内部高光；Phong Shading 插值法线后逐片元计算光照，表面更平滑、成本更高。

Phong Shading 是着色位置的选择，Phong 光照模型是高光公式，两者不是同一个概念。

### 22. Mipmap 是什么？有什么作用和存储成本？

**答案：**

Mipmap 是逐级降低分辨率的纹理链，用于纹理缩小时对像素覆盖的纹素范围做预过滤，减少远处闪烁和摩尔纹，并改善采样局部性。

完整方形二维链总像素量约 `1+1/4+1/16+…=4/3`，比基础层多约三分之一。最大层数为 `floor(log2(max(width,height)))+1`；实际资源可只创建部分层。

### 23. GPU 如何选择 Mip 层级？

**答案：**

根据 UV 的屏幕导数估计一个像素覆盖多少纹素：

```text
dx = (width × ddx(u), height × ddx(v))
dy = (width × ddy(u), height × ddy(v))
lod ≈ log2(max(length(dx), length(dy)))
```

三线性过滤对相邻两个 mip 分别做双线性，再混合结果。显式 LOD／梯度接口可覆盖自动选择；归一化 UV 必须换成纹素尺度。

### 24. 最近邻、双线性、三线性和各向异性过滤有什么区别？

**答案：**

最近邻取最近纹素；双线性在一层取四个邻近纹素加权；三线性再混合相邻 mip，减轻层级切换。

斜视表面时，像素的纹理足迹呈细长形，各向异性过滤沿足迹长轴增加采样，保留短轴细节。它改善斜视模糊，但增加采样和带宽成本。

### 25. Cubemap 如何按三维方向采样？

**答案：**

以方向绝对值最大的分量选择立方体的正／负轴面，再用其他分量与主分量的比值算面内坐标；具体朝向按 API 约定。

硬件 samplerCube／TextureCube 完成选择和采样。常用于天空盒、环境反射和 IBL；反射通常用反射方向采样，接缝与跨面过滤需要正确处理。

### 26. 法线贴图和 TBN 矩阵的原理是什么？

**答案：**

法线贴图在纹理中保存表面法线扰动，使低模表现细小凹凸而不增加几何。

常用切线空间存储，采样后将值解码到 [-1,1]，再用切线 T、副切线 B、法线 N 构成的基转换到着色空间并归一化。B 需要考虑切线手性；法线贴图作为数据通常不做 sRGB 解码。它不能真正改变轮廓，位移贴图才会移动几何。

## 五、阴影与颜色

### 27. Shadow Map 的原理、步骤和常见问题是什么？

**答案：**

先从光源视角渲染最近深度；主视图着色时把接收点投到光源空间，比较当前深度与阴影图深度，更远则被遮挡。

常见问题是分辨率走样、自阴影 Acne 和偏移过大导致的 Peter Panning。可调整阴影分辨率、投影范围、深度／斜率偏移，并采用 PCF 等过滤。软阴影详见[实时渲染题库](高质量实时渲染.md)。

### 28. Shadow Volume 的原理是什么？

**答案：**

根据遮挡物相对光源的轮廓边向外挤出阴影体，借助模板计数等方法判断可见表面是否位于体内。

它不受 Shadow Map 纹素分辨率限制，但依赖几何轮廓和闭合处理，阴影体覆盖大时填充成本高。Shadow Map 更容易融入常见实时渲染流程。

### 29. Linear、Gamma 和 sRGB 有什么区别？为什么要在线性空间算光照？

**答案：**

线性颜色值与光能成比例，光照相加和混合应在线性域进行；Gamma 编码用非线性变换更有效地分配存储精度。sRGB 包含原色、白点和分段传递函数，不只是简单的 2.2 次幂。

典型流程：颜色纹理解码到线性 → 光照与合成 → 色调／显示变换 → 输出编码。法线、深度、粗糙度等数据纹理通常不做 sRGB 解码。

### 30. HDR 是什么？Tone Mapping 有什么作用？

**答案：**

HDR 保存较大亮度范围，场景颜色可超过 1，常用浮点纹理。Tone Mapping 把场景亮度映射到目标显示范围，保留高光和暗部层次。

曝光调节整体亮度尺度，色调映射压缩或适配亮度，最终再按 SDR／HDR 输出要求编码。Bloom 等效果通常利用 HDR 高亮信息，不应先把所有值截断到 [0,1]。

## 六、常见效果与细节控制

### 31. LOD 是什么？有哪些优缺点？

**答案：**

LOD 根据物体的屏幕占比、距离或重要性选择不同细节级别。近处使用高精度模型／材质，远处降低几何、阴影和动画等成本。

优点是减少不必要的绘制与计算；代价是额外资源制作、存储和切换痕迹。可用滞回避免反复切换，用渐变减少跳变，但过渡期间可能增加绘制。只减面数未必改善透明填充或带宽瓶颈。

### 32. 水面倒影如何实现？

**答案：**

平面反射用镜像相机渲染水面另一侧场景，倒影准确但增加一次视图成本；Cubemap／反射探针采样较便宜，但有局部视差和动态更新限制；SSR 利用屏幕深度与颜色，细节丰富但缺失离屏内容。

水面通常将这些反射来源与 Fresnel、波动法线、折射和深度颜色组合。法线／UV 扰动只改变反射采样，并不自行生成场景倒影；无有效 SSR 时可回退到探针。
