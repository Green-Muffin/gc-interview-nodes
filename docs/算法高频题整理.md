## 一、排序与查找

### 1. 常见排序算法的复杂度和稳定性如何比较？

**答案：**

稳定排序保持等价元素原有顺序。下面是常见实现：

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 冒泡／插入 | O(n²) | O(n²) | O(1) | 可稳定 |
| 选择 | O(n²) | O(n²) | O(1) | 通常不稳定 |
| 快速排序 | O(n log n) | O(n²) | 平均 O(log n) 递归栈 | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | 数组版 O(n) | 可稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |

计数、桶、基数排序利用键域／分布等条件，不能脱离这些条件与一般比较排序直接比较。

### 2. 快速排序的原理是什么？如何避免退化？

**答案：**

选择 pivot，将元素划分到两侧，再递归处理。划分均衡时为 O(n log n)，持续极端不均衡时可退化为 O(n²)。

随机 pivot、三数取中改善常见分布，三路划分处理大量重复值；递归过深时转堆排序可控制最坏复杂度。实现时明确左右边界和指针推进，优先递归较短区间可降低栈深度。

### 3. 二分查找怎么处理边界和重复值？

**答案：**

先确定区间约定，例如 `[left,right)`。寻找第一个不小于 target 的位置时：

```text
left = 0，right = n
while left < right:
    mid = left + (right-left)/2
    if a[mid] < target: left = mid+1
    else: right = mid
返回 left；等于 n 表示不存在这样的元素
```

改成 `a[mid] <= target` 可找第一个大于目标的位置。输入需按对应规则有序／分区，返回位置不等于目标一定存在。

### 4. 堆的原理是什么？为什么建堆是 O(n)？

**答案：**

二叉堆是满足父子大小关系的完全二叉树，可用连续数组存储。插入从末尾上浮，删除堆顶时用末尾替换后下沉，调整成本 O(log n)，取顶 O(1)。

自底向上建堆从最后一个非叶节点开始下沉，大多数节点离叶子很近，按各高度节点数累加，总成本为 O(n)。常用于优先队列、调度和 TopK。

### 5. 如何求 TopK？

**答案：**

前 k 大可维护一个大小为 k 的小顶堆：遍历时若堆未满则插入，否则仅用比堆顶大的元素替换堆顶。时间 O(n log k)，空间 O(k)，适合流式输入。

允许修改内存数组时可用 Quickselect，平均 O(n)；STL 可用 nth_element。若前 k 项还需排好序，可用 partial_sort 或再排序结果。处理 k=0、k>n 和重复值规则。

## 二、链表、栈和树

### 6. 数组与链表有什么区别？

**答案：**

数组连续存储，随机访问 O(1)、遍历局部性好，中间插删通常 O(n)；链表按节点连接，已知相应位置时链接插删 O(1)，但定位需 O(n)，节点指针和分配增加开销。

单链表删除通常需前驱，双链表可通过节点直接调整前后链接；哨兵节点可以统一头部和普通节点的操作。

定长数组扩容优化：预分配 `reserve` 消除反复重分配；倍增式扩容保证摊还 O(1)，同时注意 1.5／2 倍系数的内存驻留差异；收缩设阈值防止在临界容量来回抖动；元素地址不能变的场合改用“稳定 ID＋内部池”（见第 17 题 SparseSet），外部只持 ID 不持指针，扩容移动后引用不悬垂。

### 7. 如何反转单链表？

**答案：**

用 prev、current、next 三个指针，先保存后继，再反转当前链接并向前推进。

```cpp
struct Node { int value; Node* next; };
Node* reverse(Node* current) {
    Node* previous = nullptr;
    while (current) {
        Node* next = current->next;
        current->next = previous;
        previous = current;
        current = next;
    }
    return previous;
}
```

时间 O(n)、额外空间 O(1)，要求输入为无环链表。

### 8. 如何判断链表有环并找到环入口？

**答案：**

slow 每次走一步，fast 每次两步；若 fast 到空则无环，若相遇则有环。

相遇后将一个指针移回头部，两个指针都每次一步，再次相遇就是入口。总时间 O(n)、空间 O(1)，每次读 fast.next 前先检查非空。

### 9. 如何找链表倒数第 k 个节点、合并两个有序链表？

**答案：**

找倒数第 k 个：先让 fast 比 slow 多走 k 步，再同步前进，fast 到空时 slow 为目标；处理 k≤0 和长度不足。

合并有序链表：用哨兵和尾指针，反复接入两条链头中较小的节点，最后接上剩余链。时间 O(n+m)，复用节点时额外空间 O(1)，调用方应允许修改原链。

### 10. 栈、队列和循环队列如何实现？

**答案：**

栈后进先出，适合括号匹配、撤销和 DFS；队列先进先出，适合 BFS 和任务处理。

可用数组或链表实现；循环数组通过取模让 head／tail 回绕，使用独立 size 或预留一个槽区分空满。双栈也能实现队列：出栈为空时将入栈整体倒入，操作摊还 O(1)。

### 11. 单调栈和单调队列解决什么问题？

**答案：**

单调栈维护尚未找到答案的单调候选，常用于下一个更大元素、柱状图等；单调 deque 在保持值单调的同时从队首移除过期索引，可求滑动窗口极值。

每个索引最多入队／栈一次、出一次，整体 O(n)。相等元素是否保留要按题目所需的最近／最远位置确定。

### 12. 二叉树有哪些遍历方式？如何判断完全二叉树？

**答案：**

前序为根左右，中序为左根右，后序为左右根，层序用队列。递归遍历时间 O(n)、栈 O(h)，深树可用显式栈。

判断完全二叉树可按层访问孩子：遇到第一个空位置后，后面不能再出现非空节点。BST 则要求整个左右子树满足键序，不能只比较直接孩子。

### 13. 如何求二叉树最大深度和最近公共祖先？

**答案：**

最大深度：空树为 0，非空为 `1+max(leftDepth,rightDepth)`。

LCA：当前节点为空或命中目标则返回；分别查左右，两侧都找到目标则当前点为祖先，否则返回找到的一侧。这个简式假设两个目标都存在，否则需同时验证找到的目标数。遍历 O(n)，递归栈 O(h)。

### 14. 红黑树与 AVL 树有什么区别？

**答案：**

二者都维持搜索树的对数高度，避免普通 BST 退化为链。AVL 对每个节点左右高度差要求更严格；红黑树用颜色、无连续红节点和相同黑高等规则约束高度。

插入删除通过旋转和状态调整恢复平衡，旋转保持中序键序。选择还要结合更新频率、缓存和具体实现；map／set 常用红黑树，但标准关注接口和复杂度保证。

## 三、哈希与常用结构

### 15. 哈希表如何处理冲突和扩容？

**答案：**

哈希函数把键映到桶，冲突可用链地址法或开放寻址处理。负载过高时扩大容量并重哈希，使元素分布到新的桶／位置。

平均查询 O(1)，最坏 O(n)，还取决于哈希质量和键成本。开放寻址删除需保留查找链，可用墓碑或合适的后移方法；桶数不必一定是质数。STL unordered 默认最大负载因子为 1.0。

### 16. LRU Cache 怎么实现？

**答案：**

用哈希表定位节点，用双向链表维护使用顺序：get 命中后移到头部，put 新增或更新后也移到头部，超容量时删除尾节点并清除哈希索引。

平均 get／put 为 O(1)，空间 O(capacity)。需要处理容量为 0、重复 key、索引与链表一致性，以及并发访问的同步。

### 17. SparseSet 的原理是什么？

**答案：**

dense 连续保存存活 ID，sparse 按 ID 保存其在 dense 中的位置。查询检查范围并验证 `dense[sparse[id]]==id`。

新增写入 dense 尾部并更新反向索引；删除用尾元素覆盖目标位置，再更新尾元素的 sparse。删除 O(1)、遍历紧凑，但不保持顺序；ID 域大时 sparse 占内存，可分页。实体复用还可用 generation 防止旧句柄误命中。

### 18. Bitmap 和 Bloom Filter 有什么区别？

**答案：**

Bitmap 对有限整数域用一位记录一个值，精确判断存在性，n 位约需 ceil(n/8) 字节。

Bloom Filter 对每个 key 用多个哈希置位，任一位为零表示不存在，全为一表示可能存在。它节省空间但有假阳性，普通版本不能直接清位删除 key，需计数等扩展。共享存储字的并发写要同步。

### 19. 并查集、Trie 和跳表分别适合什么场景？

**答案：**

并查集维护集合连通关系，路径压缩＋按秩合并使操作摊还为逆 Ackermann 量级，适合合并和连通性查询。

Trie 按字符前缀共享路径，适合前缀搜索和自动补全，空间成本与字符集有关。跳表用多级索引链表加速有序查找，常见随机实现期望 O(log n)，支持范围遍历。

## 四、搜索与算法思想

### 20. DFS 和 BFS 的区别与复杂度是什么？

**答案：**

DFS 使用递归或栈沿分支深入，适合连通性、回溯与环检测；BFS 用队列逐层扩展，在无权／等权图中得到最少边数路径。

邻接表下遍历全图通常 O(V+E)，辅助空间可达 O(V)。BFS 入队时标记访问；普通连通性 DFS 不撤销 visited，枚举路径的回溯才按分支恢复状态。

### 21. A* 的原理和实现步骤是什么？

**答案：**

`f(n) = g(n) + h(n)`：g 为起点到当前节点已知路径代价，h 为到目标的估计代价。用优先队列维护候选节点，父指针用于回溯路径。

```text
g[start] = 0，其余为无穷大；将 start 入队
循环直到队列为空：
    取 f 最小的有效条目；跳过过期条目
    若为 goal，则沿 parent 还原路径
    对每个可达邻居 v：
        tentative = g[current] + cost(current, v)
        若 tentative < g[v]：
            更新 g[v] 和 parent[v]
            以 g[v] + h(v) 入队；按策略重新开放改进的节点
队列为空仍未到达目标，则不可达
```

在常见非负边权条件下，不高估的启发式有助于保证最优性；图搜索若不重开已关闭节点，通常还需一致性条件 `h(u) ≤ cost(u,v)+h(v)`。`h=0` 对应 Dijkstra。

四方向单位网格常用曼哈顿距离，八方向移动需采用与对角代价匹配的估计。障碍角落能否穿越、动态障碍、不可达目标和代价单位都需明确，不能只背公式。

### 22. A* 如何优化？

**答案：**

缓存静态导航数据、复用搜索容器，减少邻居生成和无效堆条目；按帧预算分批搜索，大地图可采用分层导航。

启发式要与移动代价匹配，地图改变时使旧结果失效。优化应先保证可达性和最优性要求，再权衡搜索速度与路径质量。

### 23. 拓扑排序如何实现？如何判断图中有环？

**答案：**

Kahn 算法将所有零入度节点入队，取出后减少其后继入度，新的零入度节点继续入队。处理数量少于节点总数表示存在有向环，复杂度 O(V+E)。

有向图 DFS 也可用未访问／当前路径中／已完成三色判环；遇到当前路径中的节点则有环。无向图要排除父边，多重边时用边 ID 区分。

### 24. BFS、Dijkstra、Bellman–Ford 和 Floyd 分别适合什么最短路问题？

**答案：**

BFS 适合无权／等权图；Dijkstra 适合非负边权，优先队列版需要跳过过期距离；Bellman–Ford 可处理负权并检测相关负环；Floyd–Warshall 适合规模较小的全点对最短路。

距离累加要防溢出。带钥匙、门禁等条件的网格搜索，应把附加状态纳入 visited，不能只按坐标去重。

### 25. 贪心、动态规划、回溯、分治和滑动窗口如何选择？

**答案：**

贪心每步选局部最优，需要证明不会损失全局最优；DP 定义能概括后续信息的状态，通过转移复用子结果；回溯枚举选择并撤销状态。

分治将问题拆成子问题再合并，如归并排序；滑动窗口维护连续区间，适合边界能单调推进的问题。先写状态、不变量和转移条件，再选实现；不能把所有连续区间题都套滑动窗口。

## 五、手写与游戏题

### 26. 如何求第 n 个斐波那契数并处理溢出？

**答案：**

先明确 `F(0)=0、F(1)=1`。朴素递归重复计算，时间呈指数增长；缓存或迭代可在线性次数内完成。下面使用 BigInteger 表达任意精度结果，n 为非负整数。

```csharp
static System.Numerics.BigInteger Fibonacci(int n)
{
    if (n < 0) throw new System.ArgumentOutOfRangeException(nameof(n));
    System.Numerics.BigInteger a = 0, b = 1;
    for (int i = 0; i < n; i++)
    {
        var next = a + b;
        a = b;
        b = next;
    }
    return a;
}
```

迭代需要 O(n) 次加法、固定数量的大整数变量，但大整数的位数随 n 增长，不能把位复杂度也当作 O(n) 时间／O(1) 空间。快速倍增可以减少递推层数。

### 27. 如何实现“相同颜色四连通，达到三格就消除”？

**答案：**

先明确规则：这是**连通块消除**，不是只匹配连续横线／竖线的传统三消。搜索时记录 visited，避免循环访问和重复计数。

下面约定 `None` 是空格；0 可以是合法颜色。一次扫描先找出所有符合条件的连通块，随后统一清除，不在搜索中回溯恢复已访问状态。

```python
def clear_components(board, min_size=3):
    if min_size < 1:
        raise ValueError("min_size must be positive")
    if not board:
        return 0
    rows, cols = len(board), len(board[0])
    if any(len(row) != cols for row in board):
        raise ValueError("board must be rectangular")
    visited, doomed = set(), set()
    for r in range(rows):
        for c in range(cols):
            if board[r][c] is None or (r, c) in visited:
                continue
            color = board[r][c]
            stack, group = [(r, c)], []
            visited.add((r, c))
            while stack:
                x, y = stack.pop()
                group.append((x, y))
                for nx, ny in ((x-1,y), (x+1,y), (x,y-1), (x,y+1)):
                    if (0 <= nx < rows and 0 <= ny < cols
                            and (nx, ny) not in visited
                            and board[nx][ny] == color):
                        visited.add((nx, ny))
                        stack.append((nx, ny))
            if len(group) >= min_size:
                doomed.update(group)
    for r, c in doomed:
        board[r][c] = None
    return len(doomed)
```

时间和辅助空间均为 O(行数 × 列数)。如果规则含下落、补充和连锁，应在这一轮完成后分阶段执行，再重新检测。

### 28. 传统三消怎么实现？与连通块消除有什么区别？

**答案：**

传统三消扫描横向／纵向连续同色段，达到长度后先标记，再统一清除，之后下落、补充和再次检测连锁。

连通块消除只要求四连通，不要求成直线。例如 L 形三个格可能属于同一连通块，却没有横竖三连。交叉位置应只计一次，特殊棋子与交换有效性另按规则处理。

### 29. 如何手写 strcpy？为什么返回目标首地址？

**答案：**

下面保留经典 C 接口的调用契约：指针有效、源以空字符结尾、目标容量足够且两段内存不重叠。原签名没有容量参数，函数无法自行保证目标空间足够。

```c
char *copy_string(char *dest, const char *src)
{
    char *begin = dest;
    while ((*dest++ = *src++) != '\0')
    {
    }
    return begin;
}
```

返回首地址便于调用者继续使用目标字符串或组合表达式，而不是返回已经移动到末尾的指针。工程接口可显式接收容量并返回状态；重叠复制需另外设计，不可直接套用这个循环。

### 30. 如何用 C 风格数组实现可扩容队列？

**答案：**

用连续数组保存元素，维护 `head`、`size`、`capacity`，逻辑下标 i 对应物理位置 `(head+i)%capacity`。入队写 `(head+size)%capacity`，出队移动 head 并减少 size。

容量不足时申请更大数组，按逻辑顺序把旧元素复制／移动到新数组的 0..size−1，释放旧数组并令 head=0。扩容失败时保留原队列；非平凡 C++ 对象还要正确构造、销毁和处理异常，工程中优先使用标准容器。

### 31. 多线程队列如何设计？无锁队列需要解决什么问题？

**答案：**

简单方案用 mutex 保护队列状态，并用 condition_variable 在“非空／未满”条件上等待；锁必须覆盖 head、tail、size 和元素生命周期的一致更新。

无锁队列用原子 head／tail 和 CAS 推进位置。SPSC 环形队列只有一个生产者和消费者，设计相对简单；MPMC 需要槽位序号等协议，处理发布顺序、ABA、缓存行争用和安全内存回收。无锁表示整体进展保证，不代表无等待或一定更快，应使用成熟实现。

### 32. 接雨水问题有哪些解法？

**答案：**

位置 i 的水量是 `min(leftMax[i], rightMax[i])−height[i]`。可预处理左右最大值，时间 O(n)、空间 O(n)。

空间 O(1) 的双指针维护 leftMax、rightMax：较低一侧的上界已经由该侧最大值确定，累加后向中间移动。单调栈也可在遇到更高柱时结算凹槽，时间 O(n)、空间 O(n)。先处理空输入和不足三根柱子。

### 33. 如何实现洗牌算法？如何证明它是均匀的？

**答案：**

Fisher–Yates 洗牌：从后往前，第 i 轮在 `[0, i]` 中等概率选下标 j，交换 `a[i]` 与 `a[j]`。

```cpp
std::mt19937 rng(std::random_device{}());
for (int i = n - 1; i > 0; --i) {
    std::uniform_int_distribution<int> dist(0, i);
    std::swap(a[i], a[dist(rng)]);
}
```

均匀性证明：某个排列出现，当且仅当每轮恰好选中对应元素，概率为 `1/n × 1/(n-1) × … × 1/1 = 1/n!`，所有排列等概率。时间 O(n)、空间 O(1)，只需一次遍历。

错误写法要能指出：每轮在 `[0, n-1]` 全范围随机交换（有偏，部分排列概率不等）；“按随机比较器排序”既不均匀也可能未定义行为（比较器不满足严格弱序）。卡牌游戏追问通常是“抽牌怎么实现”——洗好后从尾部弹出即可，不必每抽一张重新洗。
