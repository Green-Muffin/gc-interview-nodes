## 一、向量与变换

### 1. 点积、叉积与正交基怎样服务几何计算？

`a·b = |a||b|cosθ` 表示投影关系，归一化后可比较方向。叉积大小为平行四边形面积，方向依坐标约定；二维标量叉积 `ax by−ay bx` 可判断有向面积和左右关系。

两两垂直的单位向量组成正交基，点在基上的分量可由点积求出。构造基要处理零向量和近平行方向；归一化并不能修复这些退化输入。人物左右判断可直接用 `dot(right,target−position)`，水平判断先投影到相应平面。

### 2. 齐次坐标与变换顺序为什么重要？

二维仿射变换用 3×3，三维用 4×4 齐次矩阵。位置 w=1，方向 w=0，使平移只影响位置。采用列向量时 `M₂ M₁ p` 先执行 M₁，行向量相反。

绕点 c 旋转为 `T(c) R T(−c)`。缩放、错切、反射、旋转和位移一般不可交换；物体的局部／世界操作应明确乘在哪侧。非仿射透视变换还需除以 w，不应把它与仿射变换一概处理。

### 3. 欧拉角、Rodrigues 与四元数如何选择？

欧拉角直观，但参数化可出现万向锁；单位轴 n 与角 θ 可用 Rodrigues 公式直接旋转向量：

```text
v' = v cosθ + (n × v) sinθ + n(n·v)(1−cosθ)
```

单位四元数可紧凑表达旋转，`q` 与 `−q` 表示同一个旋转。复合顺序不交换，插值通常先调整符号再做 slerp／nlerp；nlerp 后必须归一化，且一般不是等角速度。

四元数避免欧拉角的参数奇异，不自动解决相机控制、限位与旋转路径的业务选择。

### 4. 法线为什么用逆转置？

法线需要始终垂直于变换后的切平面。若线性变换为 A，则法线方向应按 `A⁻ᵀ n` 变换后归一化；直接乘 A 在非均匀缩放或错切下通常错误。

纯旋转时逆转置等于旋转本身。奇异变换不可直接求逆，负缩放还会改变绕序／手性。切线空间法线需统一 TBN、顶点变换与贴图烘焙约定。

## 二、几何与加速结构

### 5. 射线与球、三角形、AABB 如何求交？

射线 `r(t)=o+td`，需定义 `t_min`、`t_max`；d 不归一化时 t 不直接等于世界距离。

| 图元 | 算法 | 关键边界 |
| --- | --- | --- |
| 球 | 代入球方程，求关于 t 的二次方程 | 判别式、根的稳定计算、起点在球内 |
| 三角形 | Möller–Trumbore 同时求 t 和重心坐标 | 近平行、背面、共享边一致性、退化三角形 |
| AABB | Slab 各轴求 t 区间并取交 | 零方向、起点在盒内、无穷值与精度 |
| 二维线段 | 叉积求射线 t 与线段 u | 平行／共线、t≥0、0≤u≤1 |

球面二次式系数为 `A=d·d`、`B=2d·(o−c)`、`C=(o−c)·(o−c)−r²`；三角形交点满足 `o+td=p₀+u(p₁−p₀)+v(p₂−p₀)`，并检查 u≥0、v≥0、u+v≤1。Slab 伪代码见原题库第 7 题。

### 6. 均匀网格、KD 树与 BVH 如何比较？

| 方法 | 划分对象 | 优势 | 局限 |
| --- | --- | --- | --- |
| 均匀网格 | 规则空间单元 | 构建和 DDA 遍历直观 | 稀疏／高度不均分布效果差 |
| KD 树 | 按轴平面递归分割空间 | 可精细隔离空间 | 图元跨区可能重复，动态更新复杂 |
| BVH | 图元集合的包围体层次 | 构建／更新灵活，常用于硬件 RT | 子包围体可能重叠，坏层级遍历昂贵 |

SAH 以表面积估计访问概率，在构建成本与遍历成本间取舍。普通对象划分 BVH 可每图元一个叶归属，但空间划分变体可能复制图元。平均效率不等于最坏复杂度保证；反复 refit 后包围盒变松可能需要重建。

### 7. 隐式、显式、参数化与 SDF 各适合什么？

隐式表面用 `f(x,y,z)=0` 定义，符号可表达内外；显式网格直接存顶点／面，点云存离散样本；参数化曲面用 `(u,v)→p` 表达位置。参数曲面常归入显式表示，但“高度函数 z=f(x,y)”仅是特殊形式。

隐式表示便于布尔组合和内外测试，却可能难以直接采样表面；网格易于渲染但拓扑变化更复杂。SDF 进一步编码最近表面距离，CSG 常用 min／max 等组合，但组合后的函数未必处处保持精确欧氏距离，不能无条件使用原来的最大步长保证。

### 8. Bézier 与 de Casteljau 怎样求值？

n 次 Bézier 由 n+1 个控制点和 Bernstein 基加权组成。de Casteljau 在参数 t 下对相邻点重复线性插值，直到剩一点，适合几何理解与稳定求值。

曲线通过首尾控制点，端点切线由首末控制边决定，位于控制点凸包内，具有仿射不变性。分段三次曲线比单条很高阶曲线更易控制。

拼接 C⁰ 要求端点重合，C¹ 要求参数导数相等，G¹ 只要求几何切线同向；不同段参数区间会改变导数尺度，不能只看控制边共线就断言 C¹。

### 9. B 样条、NURBS 与 Bézier 曲面有什么特点？

B 样条采用局部支撑基，移动一个控制点通常只影响邻近区间；连续性依次数和 knot 重数而定，并非天然处处高阶连续。NURBS 加入权重与非均匀节点，可精确表达适当的圆锥曲线等，常用于 CAD。

双三次 Bézier 曲面使用 4×4 控制点，先沿 u 对各行求值，再沿 v 对所得点求值，是张量积曲面。OBJ 可存顶点、UV、法线和面索引；网格数据不只位置，还可能有接缝处的独立属性索引。

### 10. Loop 与 Catmull–Clark 细分怎样处理网格？

Loop 适用于三角形网格：每边生成点并更新旧顶点，新边点通常综合端点与相邻对顶点；边界有专门规则。Catmull–Clark 面点、边点与旧顶点共同更新，通常一轮将多边形网格转为四边形网格。

奇异顶点指邻接度不满足规则网格情况，不等于“所有非四边形面永远保持原形”。折痕、边界和非流形输入需要特别处理；增加面数并不自动修复坏拓扑或保留所有锐边。

### 11. QEM 边折叠与重网格化解决什么问题？

QEM 为顶点关联平面构建二次误差矩阵，候选折叠点的代价为到这些平面的加权平方距离。选择低代价边折叠并更新邻域，直到达到面数或误差预算。

最小二次型可能奇异，需端点／中点等回退；还要防止翻面、自交和破坏材质边界、UV 或轮廓。重网格化通过分裂、折叠、翻边、顶点重定位改善采样质量，目的不同于只减少三角形的 LOD 简化。

## 三、相机与光的度量

### 12. 辐射度量中的能量、通量、强度、辐照度与辐亮度是什么？

| 量 | 符号／单位 | 定义方向 |
| --- | --- | --- |
| 辐射能量 | Q，J | 总能量 |
| 辐射通量 | Φ，W | 单位时间能量 |
| 辐射强度 | I，W/sr | 每立体角通量 |
| 辐照度 | E，W/m² | 单位接收面积通量 |
| 辐亮度 | L，W/(m²·sr) | 每投影面积、每立体角的通量 |

整球立体角为 4π sr。辐亮度定义中的投影面积含余弦关系，渲染方程以其为主要量。光度学量还按人眼光谱响应加权，流明／勒克斯不能不经转换直接等同瓦特。

BRDF 是出射辐亮度变化对入射辐照度变化的比率，单位 sr⁻¹，不是一个必须≤1的普通概率；能量守恒约束的是带余弦的方向积分。互易性适用于相应互易介质和模型，不能推广到全部非互易／荧光传输。

### 13. 薄透镜、FOV、景深与曝光如何联系？

薄透镜近似 `1/f = 1/z_object + 1/z_image`；传感器尺寸固定时焦距短通常 FOV 大。光圈 f-number 为焦距除以有效孔径直径，数值小代表孔径大，通常景深更浅。

快门决定积分时间，孔径决定光通量与景深，ISO 通常代表相关增益／曝光标定而非制造额外光子。等效亮度不等于相同噪声、动态范围或运动效果。

光圈上的位置采样对应景深，快门时间采样对应运动模糊。屏幕后处理只是对有限图像信息的近似重建，不能完整恢复被前景遮挡的背景。

### 14. 光场与全光函数为什么有不同维数？

完整全光函数可依位置三维、方向二维、时间和波长而变化。常用 4D 光场假设固定时间／光谱并处于无参与介质的自由空间，用两平面交点参数化光线。

因此不能把“任意位置＋任意方向”直接算成 2+2 维。光场相机采集方向信息后可支持有限重对焦或视点变化，但有空间／角度分辨率和遮挡范围的限制。

### 15. 三刺激、同色异谱与常见颜色空间怎样解释？

可见光范围常近似为 380–780 nm，边界依定义与观察条件而变化。视锥 S／M／L 有重叠光谱响应，视杆在暗视觉中作用更强。不同光谱在给定观察者／条件下产生相同三刺激值称为同色异谱，不保证换光源或观察者后仍相同。

| 空间／模型 | 用途 | 边界 |
| --- | --- | --- |
| CIE XYZ | 标准色度学三刺激，Y 对应亮度量 | 不等于某显示设备的可显示色域 |
| sRGB | 规定原色、白点与传递函数 | 色域有限，不能表示所有可见颜色 |
| HSV | 基于 RGB 的直观选色参数 | 不是感知均匀空间 |
| CIELAB | 近似感知均匀的色差表示 | 依参考白和适用条件，非处处完美 |
| CMYK | 印刷减色控制模型 | 结果依油墨、纸张、ICC 配置 |

颜色恒常性与同时对比说明感知依上下文。线性域运算与显示编码见基础篇，不能用“人只有三类视锥”推出某台 RGB 屏幕可显示所有光谱颜色。

## 四、动画与模拟

### 16. 骨骼层级、逆绑定矩阵与 LBS 怎样组合？

父子局部变换逐级相乘得到姿态。若顶点在绑定模型空间，当前骨骼变换也表达在该模型空间，则蒙皮矩阵可写为 `M_i = B_i,current × B_i,bind⁻¹`，位置为 `Σ w_i M_i p`，权重通常归一化。

若使用世界空间骨骼矩阵，输出空间也会变化，可能需要当前模型矩阵的逆来转换，不能重复乘模型变换。逆绑定矩阵的职责是把绑定顶点带回相应骨骼坐标关系。

每顶点 4 骨影响很常见，但不是语言或 GPU 的固定上限。法线变换需按变形近似处理；常见加权旋转／矩阵近似不等于完整变形场精确逆转置，非均匀缩放尤其敏感。

### 17. LBS、DQS 与 Blend Shape 有什么区别？

LBS 对矩阵结果加权，便宜且通用，但混合旋转可能导致关节体积塌陷或糖纸扭曲。DQS 用双四元数混合刚体变换，改善这类伪影，但符号、尺度和非刚体变形需额外处理。

Blend Shape 直接对目标顶点形状加权，适合表情和矫正；可与骨骼蒙皮一起使用，顺序须遵守资产约定。绑定系统还包括控制器、约束和美术调整，不只是一个骨骼数组。

### 18. 关键帧采样、动画混合与重定向如何实现？

找到时间两侧关键帧，平移／缩放做线性或样条插值，旋转使用 slerp／nlerp；在局部姿态层混合多个动画，再求骨骼层级结果。叠加动画应明确参考姿态、旋转顺序与权重。

重定向除了名字和层级映射，还依赖骨长、坐标轴、休息姿态和目标约束。动捕可用光学、惯性等手段获取姿态，但噪声、脚滑和接触仍需修正。

优化可做曲线压缩／量化、采样共享、更新频率 LOD、减少骨影响和 GPU 蒙皮。CPU 求姿态、GPU 顶点或 Compute 蒙皮都有适用条件，不存在所有项目都固定“CPU 是主要瓶颈”或“骨数只能 64–256”。

### 19. FK 与 IK 如何选？

FK 从关节姿态沿层级求末端位置，适合动画控制；IK 给末端目标反求姿态，可用解析双骨、CCD、FABRIK 或数值优化等方法。

IK 可能多解、无解或遇到奇异位置，需要关节限位、姿态偏好、阻尼与目标可达性处理。最终常将动画姿态与 IK 修正混合，而非让所有关节每帧完全由 IK 决定。

### 20. 质点弹簧和粒子系统怎样步进？

质点携带位置、速度、质量，弹簧沿连接方向施加与伸长相关的恢复力，并以阻尼耗散能量。布料可建结构、剪切、弯曲约束／弹簧；刚度越高，对显式时间步通常越敏感。

粒子系统把生成、受力、积分、碰撞、寿命和渲染分开，烟火水花常采用视觉近似。GPU 并行适合大量相似计算，但邻域查询、排序、交互和绘制带宽会限制规模，不能只按宣传粒子数判断性能。

### 21. 显式、半隐式、隐式欧拉与 Verlet 如何比较？

| 积分器 | 核心 | 权衡 |
| --- | --- | --- |
| 显式欧拉 | 用当前导数更新全部状态 | 便宜，一阶；刚性／振荡系统需小步长 |
| 半隐式欧拉 | 先更新速度，再用新速度更新位置 | 游戏常用，稳定性／能量表现常优于朴素显式 |
| 中点／RK2 | 中间状态估计导数 | 二阶，但仍有稳定域限制 |
| RK4 | 每步多次求导 | 高阶精度不等于刚性问题无条件稳定 |
| 隐式欧拉 | 以未来状态列方程求解 | 对某些线性稳定系统 A-stable，耗散较强，求解有成本 |
| Verlet | 利用位置历史／速度形式更新 | 适合一些力学／约束系统，时间步和碰撞仍需管理 |

“隐式欧拉对一切系统和任意求解误差都稳定”不成立；非线性、接触与近似求解会改变表现。固定步长、子步进、约束迭代和渲染插值需一起设计。

### 22. 刚体、SPH、网格流体与 MPM 有何不同？

刚体用位置、朝向、线／角速度描述运动，转动由力矩与惯性张量控制。宽相筛候选、窄相生成接触，再用冲量／约束求解器处理非穿透、摩擦和恢复；高速运动还需连续碰撞检测等措施。

SPH 等拉格朗日方法跟踪粒子，便于自由表面，但邻域搜索与密度稳定有成本。欧拉网格方法在固定网格求速度／压力，便于空间算子，但有数值耗散和边界分辨率问题。MPM 在粒子和背景网格间传递信息，适合某些大变形材料，仍依赖本构模型、稳定时间步与接触处理。

角色观感还受动作节奏、眼神、接触和材质一致性影响；“恐怖谷”可作为感知讨论，不应把风格化或写实当成总能规避问题的定律。

## 复习顺序

先练向量、坐标与射线区间，再学几何表示和层级加速；理解辐射度量后进入渲染方程；做动画时先统一空间与绑定姿态，再讨论插值和性能；模拟先说明积分与约束假设，再谈精度和稳定性。
