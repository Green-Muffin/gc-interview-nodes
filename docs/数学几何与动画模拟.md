## 一、向量与变换

### 1. 点积、叉积和归一化有什么意义？

**答案：**

点积 `a·b=|a||b|cosθ` 用于夹角、投影和方向判断。三维叉积得到垂直两向量的方向，长度为 `|a||b|sinθ`，可用于法线和有向面积。

归一化保留方向、将长度变为 1，适合光照和方向运算；零向量需先处理。比较距离大小时可用平方距离，省去开方。

### 2. 如何判断目标在人物左边还是右边？

**答案：**

设方向 `D=targetPosition−position`，与角色右方向点积：`dot(right,D)>0` 在右边，小于 0 在左边，接近 0 表示在左右分界面附近。

只判断水平左右时，先投影到选定水平面。前后用 forward 与 D 点积。也可用叉积，但符号须结合坐标轴和叉乘顺序确定。

### 3. 齐次坐标有什么作用？变换矩阵为什么不能随意交换？

**答案：**

齐次坐标让平移与旋转、缩放统一为矩阵乘法：三维位置通常写成 `(x,y,z,1)`，方向写成 `(x,y,z,0)`，这样平移不会改变方向。

列向量约定下 `M2×M1×p` 表示先 M1 再 M2。旋转后平移与平移后旋转一般结果不同，所以乘法不能交换。绕点 c 旋转可写为 `T(c)×R×T(−c)`。

### 4. 四元数有什么作用？相对欧拉角有什么优点？

**答案：**

单位四元数用四个分量表示三维旋转，适合旋转复合和插值，避免欧拉角参数化的万向锁。q 与 −q 表示同一个旋转。

Slerp 沿球面插值，适合平滑旋转；Nlerp 线性插值后归一化，更便宜但通常不是等角速度。复合顺序仍有意义，插值前通常调整四元数符号以选择较短路径。

### 5. Rodrigues 旋转公式是什么？

**答案：**

绕单位轴 n 旋转 θ 时：

```text
v' = v cosθ + (n × v) sinθ + n(n·v)(1−cosθ)
```

它把 v 拆成沿轴分量和垂直轴分量：沿轴部分不变，垂直部分在平面内旋转。可直接由轴角生成旋转，不必先分解成三个欧拉角。

### 6. 法线为什么使用逆转置矩阵变换？

**答案：**

法线需要与变换后的切平面保持垂直。线性变换为 A 时，应使用 `A⁻ᵀ×N`，然后归一化；非均匀缩放下直接乘 A 会破坏垂直关系。

纯旋转时逆转置等于旋转本身。切线空间法线还需要 TBN 和手性一致；零缩放使矩阵不可逆，应避免直接套求逆。

## 二、相交测试与加速结构

### 7. 射线与线段如何求交？

**答案：**

二维射线 `O+tD`（t≥0），线段 `A+uE`（E=B−A，0≤u≤1）。令二维叉积为 `cross(a,b)=ax by−ay bx`，当分母非零时：

```text
den = cross(D,E)
t = cross(A−O,E) / den
u = cross(A−O,D) / den
相交条件：t≥0 且 0≤u≤1
```

平行或共线时另做区间重叠判断，零方向／零长度单独处理。端点在直线两侧还不足以判断射线相交，因为交点可能位于射线原点背后。

### 8. 射线与 AABB 如何求交？

**答案：**

Slab 方法逐轴计算射线处于盒子区间内的 t 范围，再求交集。

```text
tEnter = 0，tExit = 最大距离
对每个轴：
    若 D 为 0：O 在该轴区间外则失败，否则跳过
    t1 = (min−O)/D，t2 = (max−O)/D
    若 t1>t2，交换
    tEnter = max(tEnter,t1)
    tExit = min(tExit,t2)
    若 tEnter>tExit，失败
全部通过则相交
```

D 未归一化时 t 不是直接的世界距离；旋转盒可先把射线转到盒局部空间再求交。

### 9. 射线与球、三角形如何求交？

**答案：**

球面：将 `o+td` 代入 `|p−c|²=r²`，得到二次方程，根据判别式和合法 t 范围选择最近交点。

三角形：Möller–Trumbore 求解 `o+td=p0+u(p1−p0)+v(p2−p0)`，同时得到 t 和重心坐标，检查 `u≥0、v≥0、u+v≤1`。需要处理近平行、退化三角形和共享边数值一致性。

### 10. BVH、KD 树和均匀网格有什么区别？

**答案：**

均匀网格按规则空间单元存图元，光线按穿过顺序遍历；实现直观，但分布不均时效率差。

KD 树递归分割空间，跨区域图元可能重复存储；BVH 将图元集合分组并包围，子包围体可重叠。BVH 通常较适合构建和动态更新，是常见光追加速结构。三者都通过排除大量无关图元减少求交。

## 三、几何表示与处理

### 11. 显式表示和隐式表示有什么区别？SDF 是什么？

**答案：**

显式表示直接给出表面，例如网格、点云或参数曲面，容易采样和显示；隐式表示用 `f(x,y,z)=0` 定义表面，便于判断内外和做布尔操作。

SDF 保存到最近表面的带符号距离，符号区分内外，常用于 ray marching、碰撞近似和字体。隐式表示表面采样较难，离散距离场还有分辨率和更新成本。

### 12. Bézier 曲线和 de Casteljau 算法的原理是什么？

**答案：**

Bézier 曲线由控制点和 Bernstein 基函数加权得到。de Casteljau 在参数 t 下对相邻控制点逐层线性插值，直到剩下一个点，就是曲线上的位置。

曲线经过首尾控制点，位于控制点凸包内，端点切线沿首末控制边。分段拼接中 C0 保证位置连续，C1 保证参数导数连续，G1 只保证切线方向一致。

### 13. B 样条、NURBS 和 Bézier 曲面有什么特点？

**答案：**

B 样条具有局部控制，移动控制点只影响邻近区间；连续性由次数和节点重数决定。NURBS 再加入权重，可精确表达圆锥曲线等，常用于 CAD。

双三次 Bézier 曲面有 4×4 控制点，可先沿 u 求各行曲线，再沿 v 对结果求值。它与 B 样条／NURBS 都属于常见参数化曲面表示。

### 14. Loop 细分和 Catmull–Clark 细分有什么区别？

**答案：**

Loop 用于三角形网格，在边上生成新点并按邻接关系更新旧顶点；Catmull–Clark 用面点、边点和旧顶点更新，通常一轮后形成四边形网格。

细分提高曲面平滑度，边界、折痕和奇异顶点需要对应规则。面数增长会增加存储与渲染成本，通常与细节级别控制结合。

### 15. 网格简化和 QEM 的原理是什么？

**答案：**

常用边折叠逐步将一条边的两个顶点合并。QEM 将候选新顶点到相关平面的距离平方和作为误差，选低代价边折叠，更新邻域，直到达到面数或误差目标。

优点是能较好保留整体形状；还需保护轮廓、UV 接缝和材质边界，避免翻面、自交。重网格化则侧重改善三角形质量，不只是减面。

## 四、相机与色彩

### 16. 辐射通量、强度、辐照度和辐亮度分别是什么？

**答案：**

通量 Φ 是单位时间能量，单位 W；强度 I 是每立体角通量，单位 W/sr；辐照度 E 是单位面积接收通量，单位 W/m²；辐亮度 L 是每投影面积、每立体角的通量，单位 W/(m²·sr)。

渲染方程主要使用辐亮度。点光源照射平面时，辐照度包含距离平方衰减和余弦项；光度学量还按人眼光谱响应加权。

### 17. 焦距、光圈、景深和曝光有什么关系？

**答案：**

固定传感器尺寸下，焦距越短视场通常越宽。光圈直径越大，进光越多、景深通常越浅；f-number 等于焦距除以孔径直径，因此数值越小光圈越大。

快门时间决定曝光积分时长和运动模糊，ISO 与增益／曝光标定有关。薄透镜公式 `1/f=1/zo+1/zi` 描述物距、像距与焦距关系。

### 18. 什么是同色异谱？常见颜色空间有哪些？

**答案：**

不同光谱在给定观察条件下产生相同三刺激值，看起来颜色相同，称为同色异谱。

CIE XYZ 用于标准色度描述，sRGB 定义常见显示原色、白点和编码，HSV 便于选色，CIELAB 近似感知均匀，CMYK 用于印刷。RGB 显示器有有限色域，并不能呈现所有可见颜色。线性光照与输出编码见[图形学基础](图形学基础.md)。

## 五、动画与物理模拟

### 19. 骨骼动画和线性混合蒙皮怎么实现？

**答案：**

骨骼组成层级，每根骨骼的当前变换由父变换和局部变换组合。顶点保存骨骼索引和权重，用各骨骼的蒙皮矩阵加权变形。

```text
Mi = 当前骨骼变换 × 逆绑定矩阵
p' = Σ wi × Mi × p，Σwi = 1
```

逆绑定矩阵把绑定姿态的顶点转回骨骼参考空间，当前变换再带到新姿态。两矩阵的空间约定必须一致；GPU 蒙皮通常上传骨骼矩阵，在顶点或 Compute 阶段处理。

### 20. LBS、DQS 和 Blend Shape 有什么区别？

**答案：**

LBS 对矩阵变换后的顶点加权，简单但关节可能塌陷或产生糖纸扭曲；DQS 用双四元数混合刚体变换，较好保持旋转和体积，但缩放等非刚体变化需额外处理。

Blend Shape 直接对多个目标形状的顶点位置加权，常用于表情和姿态矫正，也可与骨骼动画叠加。

### 21. 关键帧动画如何采样、插值和混合？

**答案：**

根据时间找到相邻关键帧，平移／缩放做线性或样条插值，旋转用四元数 Slerp／Nlerp。多个动画通常在骨骼局部姿态层混合，再沿层级求最终变换。

优化包括删除冗余关键帧、量化、共享采样、降低远处更新频率和动画 LOD。重定向还要匹配骨长、坐标轴和绑定姿态，不能只按骨骼名字替换。

### 22. FK 和 IK 有什么区别？

**答案：**

FK 给定各关节角度，沿骨骼层级算末端位置；IK 给定末端目标，反求关节姿态。

FK 适合预制动画，IK 常用于脚底贴地、手接触目标。IK 可用双骨解析解、CCD、FABRIK 或数值优化，需处理目标不可达、关节限位和多解；通常与基础动画混合。

### 23. 质点弹簧系统怎么模拟布料？

**答案：**

用质点表示布料节点，以结构、剪切、弯曲弹簧或约束连接。根据伸长计算恢复力，加上重力和阻尼，再积分更新位置／速度，并处理碰撞。

弹簧刚度高时显式步进需要更小时间步，容易不稳定；可采用子步进、隐式积分或约束求解。粒子系统使用类似状态更新，但烟火等效果常采用更简化的视觉模型。

### 24. 常见数值积分方法有什么区别？

**答案：**

显式欧拉用当前导数更新，简单但对刚性／振荡系统稳定性较差；半隐式欧拉先更新速度再更新位置，常用于游戏。

中点法／RK2、RK4 用更多导数采样提高精度；隐式欧拉用未来状态列方程，对一些刚性问题更稳定但求解贵且有耗散；Verlet 利用位置历史或等价速度形式，适合某些力学和约束系统。精度阶数高不等于任意步长都稳定。

### 25. 刚体、SPH、网格流体和 MPM 各怎么模拟？

**答案：**

刚体用位置、朝向、线／角速度描述运动，通过力、力矩和接触约束更新；碰撞通常先宽相筛选，再窄相求接触，最后求解冲量。

SPH 跟随粒子并通过邻域核估计流体量；欧拉网格在固定网格上求速度和压力；MPM 用粒子携带材料信息、网格完成计算，再传回粒子。选择取决于材料、自由表面、分辨率和实时成本。
