## 一、渲染方程与光线追踪

### 1. 渲染方程表达了什么？

**问题：** 给定着色点、材质和入射光，求朝某个观察方向离开的辐亮度。

```text
L_o(p, ω_o) = L_e(p, ω_o)
             + ∫_{Ω⁺} f_r(p, ω_i, ω_o) L_i(p, ω_i) max(0, n·ω_i) dω_i
```

- `L_o`：沿观察方向离开表面的辐亮度。
- `L_e`：该表面的自发光。
- `L_i`：从半球入射的辐亮度，包括环境与其他表面。
- `f_r`：BRDF，描述方向间散射。
- `max(0,n·ω_i)`：投影面积的余弦权重。
- `dω_i`：方向微分立体角，Ω⁺ 是表面上半球。

全局光照的难点在于，`L_i` 本身又由其他表面的出射光构成，因而是耦合传输问题。解析解只在有限的简化条件下可得；预计算、屏幕空间近似和随机积分各自舍弃或复用不同信息。

此处积分形式假设表面散射。若考虑参与介质，还需要沿路径的吸收、散射积分；折射材质通常要用 BSDF 处理半球两侧。

BRDF 的单位为 sr⁻¹，不能简单当作取值必须小于 1 的反射比例。若 L_i 已表示实际到达该点的光，遮挡已包含在其定义中；若用未遮挡光源辐亮度建模，则要显式加入可见性，避免重复相乘。参考：[PBRT：光传输方程](https://www.pbr-book.org/4ed/Light_Transport_I_Surface_Reflection/The_Light_Transport_Equation)。

### 2. Whitted 光线追踪解决什么问题？有什么限制？

从相机向像素发射主光线，取最近交点；在交点朝光源发阴影射线，并沿理想镜面反射／折射方向递归发射次级光线，汇总直接光与递归结果。

该法容易表达硬阴影与理想镜面效果，首次交点和次级射线需正确选取 t 范围，并偏移起点以避免自相交。它不会自动解决粗糙漫反射路径、软阴影或真实多次散射；无限递归要用最大深度或终止策略限制。

### 3. 路径追踪如何把积分变成采样？

对方向分布 `p(ω)` 采样时，半球积分可估为：

```text
L_estimate = (1/N) Σ_{k=1..N} [f_r(ω_k) L_i(ω_k) max(0,n·ω_k) / p(ω_k)]
```

射线在表面相交后依 BRDF 采样下一方向；路径 throughput 逐次乘以散射值、余弦项及采样 PDF 的比值，并累积沿途命中的发光。对同一像素增加独立样本可降低方差，典型蒙特卡洛误差约按 `1/√N` 收敛；单帧低样本率表现为噪声。

正确采样需使用对应 PDF，包含坐标变换和离散光源选择概率；漫反射下 cosine-weighted sampling 可降低方差。只说“随机方向命中光源就计亮度”漏掉了 PDF 与 throughput 权重。

只含非发光表面和独立光源的教学版本，可按下列循环理解。若将 NEE／MIS 加入实现，应同时改写光源命中权重，不能把直接光估计简单重复加入：

```text
L = 0，beta = 1，ray = 相机样本射线
循环：
    hit = 场景最近相交(ray)
    若未命中：L += beta × environment(ray.direction)；结束
    L += beta × emission(hit, -ray.direction)
    若材质没有散射：结束
    按 BSDF 采样 wi，取得 f 与方向 pdf
    若 pdf 无效或散射贡献为零：结束
    beta *= f × abs(n·wi) / pdf
    达到 RR 起始深度后：
        以 q 存活；失败则结束，成功则 beta /= q
    ray = 从交点安全偏移后沿 wi 发射
```

介质、折射传输尺度和 delta 分布需使用相应 BSDF 采样契约，这段仅解释常见表面循环。

### 4. 直接光采样与 MIS 如何减少噪声？

只按 BSDF 采样时，小光源难以命中；只按光源采样时，镜面高光窄瓣可能很难采中。重要性采样尽可能把样本放到高贡献区域，Multiple Importance Sampling（MIS）则用一致的权重结合光源采样与 BSDF 采样。

面积光源样本通常先以面积 PDF 产生，再转为方向 PDF，须包含面积到立体角的 Jacobian。光源采样与 BSDF 路径命中同一发光体时，若同时计入两项，需用兼容的 MIS 权重避免重复估计。参考：[PBRT：A Better Path Tracer](https://www.pbr-book.org/4ed/Light_Transport_I_Surface_Reflection/A_Better_Path_Tracer)。

### 5. Russian Roulette 怎样保持估计不偏？

俄罗斯轮盘赌（RR）在某个反弹后以存活概率 `q` 继续路径。若存活，后续 throughput 除以 `q`；若死亡，贡献为 0。此权重使期望值不变，但会增加方差。实际 `q` 可依据 throughput、反射率和能量尺度设置，并钳在合理区间。

```text
q = survivalProbability
若 random() >= q：结束该路径
否则：throughput /= q
```

RR 用概率控制长尾，不是“若打到光源就先除以 P”。若以终止概率 `p` 描述，则存活概率是 `1−p`，存活权重应除以 `1−p`。有限最大深度也常用，但可能截断高阶贡献而引入偏差。

参考：[PBRT：Russian Roulette 与估计效率](https://www.pbr-book.org/4ed/Monte_Carlo_Integration/Improving_Efficiency)。

### 6. 光线追踪和路径追踪的差别是什么？BVH 为什么重要？

光线追踪是一类求交与传输计算方法，Whitted、路径追踪、AO 射线等都可用；路径追踪专指以随机路径估计光传输积分的一类方法。

暴力检查 N 个三角形需逐个求交，BVH 把图元装入层次包围盒，先检查包围体、再访问叶节点，避免大量图元测试。平均表现依层级质量和光线分布，并非数学上保证 `O(log N)`；BVH 的构建质量、更新成本、访存布局及遍历顺序都影响实效。

### 7. 路径追踪如何表示介质、运动与时间？

参与介质沿光线累积透射率与散射贡献，不能只在表面命中时着色。景深通过相机光圈位置采样，运动模糊通过快门时间采样。增加这些维度通常需要更多样本。

折射、体积、运动和多次漫反射都有各自的采样分布与方差来源。随机种子应按像素、帧和样本适当变化；简单固定每像素方向可能出现结构化图案。实时降噪须获得深度、法线、速度及材质等辅助数据，但这些信号并不都能可靠描述反射路径的历史对应。

## 二、Vulkan 光线追踪管线

### 8. Vulkan RT 的能力由哪些扩展组成？

Vulkan 光追不是一个单独管线扩展包打天下。常见核心部分包括 `VK_KHR_acceleration_structure`、`VK_KHR_ray_tracing_pipeline` 和 `VK_KHR_ray_query`，并依赖相应 SPIR-V／着色器支持及设备特性；建管线等还可能涉及 deferred host operations、pipeline library。

Ray Tracing Pipeline 提供专用着色器阶段与 trace 命令；Ray Query 可从传统图形、计算等着色器显式遍历加速结构，不要求另启独立 RT pipeline。功能、格式、递归深度和描述符支持须查询设备 feature 与 limit，不能假定任意 Vulkan 设备都具备。

参考：[Khronos Vulkan Guide：Ray Tracing](https://docs.vulkan.org/guide/latest/extensions/ray_tracing.html)。

### 9. BLAS 与 TLAS 分别存什么？动态场景如何更新？

BLAS（Bottom-Level AS）表示几何集合，常见输入为三角形或 AABB 程序化几何；TLAS（Top-Level AS）表示指向 BLAS 的实例及变换、mask 和 SBT record offset 等实例数据。多个实例可以共享同一 BLAS。

若只改实例变换，常见做法是更新 TLAS；若顶点拓扑或顶点位置变了，要依据构建标志与更新条件更新 BLAS，并使上层实例状态一致。刚体移动不是所有动态物体一概“只更新 TLAS”：蒙皮几何、变形网格和更新策略均需考虑 BLAS 更新或重建成本。

Build／Update 会读写 scratch 与几何缓冲，后续射线读取 AS 前需建立正确的阶段与内存依赖。AS 是不透明实现对象，不能从应用侧当作通用顶点数组任意解释。

`PREFER_FAST_TRACE` 和 `PREFER_FAST_BUILD` 表达构建时间／遍历效率的偏好，静态物体常偏向前者，高频重建对象可能偏向后者；不是强制质量保证，也不是二者总能同时指定。原地 update 需满足 `ALLOW_UPDATE` 等构建条件和更新限制。参考：[Vulkan AS 构建标志](https://docs.vulkan.org/refpages/latest/refpages/source/VkBuildAccelerationStructureFlagBitsKHR.html)。

### 10. Ray Generation、Hit、Miss 与 Callable 各做什么？

| 阶段 | 职责 |
| --- | --- |
| Ray Generation | 为 invocation 生成主射线／次级射线并启动追踪 |
| Intersection | 对程序化 AABB 几何实现自定义相交 |
| Any Hit | 对遍历中候选交点过滤或处理，例如 Alpha Mask；可能执行多次 |
| Closest Hit | 处理被选为最近交点的命中并计算材质／后续光线 |
| Miss | 无有效几何命中时处理背景／环境 |
| Callable | 被追踪着色器调用的可调用着色程序 |

三角形的射线求交通常由实现提供；不用为普通三角形自行实现 intersection shader。Any Hit 只对有关候选交点发生，可能在确认为最近命中前多次调用，故避免昂贵或有顺序副作用的逻辑。

这些阶段不是“Intersection → Any Hit → Closest Hit → Miss”全部依次运行。一次 trace 在允许的候选过滤后，有有效命中则按 flags 等规则处理 closest hit，无有效命中才走 miss；某些阶段可被跳过。Callable 由显式调用触发，不是每条光线的固定末尾阶段。

### 11. SBT 与 recursion depth 要怎样配置？

Shader Binding Table（SBT）把着色器组 handle 和应用数据按对齐要求打包，trace 命令用 raygen、miss、hit 等区域与索引定位 record。应用须遵守设备报告的 handle alignment、base alignment、stride 与最大 stride 限制；不能把 SBT 理解成普通纹理或仅是“绑定一组 shader”。

递归深度限制 RT pipeline 中嵌套 ray trace 调用层数，并受到设备 limit 和实现资源影响。常见实时方案会用迭代路径循环控制反弹数，但选择递归还是迭代取决于架构、着色器模型与状态存储成本；“最大 4–5 层是标准”不是 API 规定。

### 12. Vulkan RT 的一帧通常怎样串起来？

简化链路：准备几何／实例缓冲 → 构建或更新 AS → 建 RT pipeline 和 SBT → 绑定描述符与 pipeline → `vkCmdTraceRaysKHR` → 将结果用于合成／降噪／输出。也可在光栅化着色器里用 Ray Query 做阴影或反射。

Pipeline 的 shader stages、shader groups、layout、递归深度和 SBT 都要互相匹配。同步必须覆盖 AS build 写到 trace 读的依赖，以及 ray tracing 对 SBT／图像等资源的读写；在跨队列情况下还要同步队列所有权和信号等待。使用 Render Graph 时依赖仍须正确建模，不能期待框架推断它看不到的访问。

参考：[Vulkan Guide：RT 同步](https://docs.vulkan.org/guide/latest/extensions/ray_tracing.html)、[Vulkan 规范：Ray Tracing](https://docs.vulkan.org/spec/latest/chapters/raytracing.html)。

## 三、PBR 与高级材质

### 13. 什么是 PBR？Metallic-Roughness 是唯一模型吗？

PBR（Physically Based Rendering）是一组让材质、光照、单位和能量关系更一致的建模实践，不是一支 Shader 或一个参数面板。实时管线通常使用微表面 BRDF、直接光、预过滤 IBL，并对复杂传输进行工程近似。

Metallic-Roughness 工作流以 Base Color、Metallic、Roughness 为常见参数；Specular-Glossiness 等也可用。模型、色彩空间、单位与光源标定不一致时，即使贴图看似符合某套范围也不保证正确。

### 14. Cook–Torrance 微表面 BRDF 的 D、F、G 分别是什么？

一种常见形式为：

```text
h = normalize(l + v)
f_s(l,v) = D(h) F(v,h) G(l,v,h)
           / [4 max(n·l, ε) max(n·v, ε)]
```

- `D`：微表面法线分布函数（NDF），估计朝半程向量 h 对齐的微面分布；如 GGX／Trowbridge–Reitz。
- `F`：Fresnel 项，描述反射率随角度的变化；Schlick 近似为 `F₀+(1−F₀)(1−V·H)^5`。
- `G`：微表面间的遮蔽与阴影，常以 Smith G 项表示。

分母和项定义依具体 NDF／BRDF 约定。`D` 可能按立体角或斜率空间归一化；不同实现的 roughness 参数化、G 项和可见法线采样不可混拼。`max` epsilon 只能避免数值病态，不替代入射半球裁剪。

### 15. 电介质与金属的 F₀、粗糙度如何影响外观？

普通电介质正入射 F₀ 通常近似为低值，且其漫反射颜色可见；导体反射颜色与波长有关，金属工作流常将 Base Color 用作有色镜面反射，并压低／移除漫反射项。

粗糙度增大时微表面高光通常变宽并降低峰值，环境反射也更模糊；具体峰值和能量取决于 BRDF 是否归一化与多次散射补偿。金属度是工作流插值参数，不是现实材质微观结构的独立开关。

### 16. Split-Sum IBL 怎样近似环境积分？

Split-Sum 把镜面环境积分分为两部分预计算：按 roughness 对环境图做预滤波，得到 roughness-dependent environment；再把 BRDF 积分在常见近似下压缩进依赖 `N·V` 与 roughness 的 2D LUT。

运行时从预滤波图按反射方向／粗糙度取样，再结合 LUT 与 F₀ 拼出近似 specular IBL。它减少实时求积，代价是分解近似、预过滤核、LUT 约定和 BRDF 必须匹配，并非对任意环境与视线完全精确。漫反射 IBL 常另用辐照度卷积或 SH。

### 17. 多重微表面反射为什么需要能量补偿？

单次散射微表面模型中，被微观遮挡或多次反射后逸出的能量可能没有计入。高粗糙度时这种遗漏较明显，使材质偏暗。

可用离线生成的 LUT 或解析近似补偿多次散射能量；Kulla–Conty 一类方法提供此类思路。补偿须与原模型能量账本匹配，直接加一个任意 diffuse lobe 不会自动物理正确，也不应把所有引擎的实现视为同一个公式。

这里的“能量损失”是模型遗漏可能重新逸出的多次散射；单次散射总能量不超过入射仍符合能量不增约束，不能把偏暗和“凭空增能”混为一类。实现参考：[Filament：材质与多次散射补偿](https://google.github.io/filament/main/filament.html)。

### 18. LTC 如何让多边形面光源更高效？

矩形灯等面积光源若直接按多点随机采样会有噪声或成本。LTC（Linearly Transformed Cosines）拟合特定视角与粗糙度下的 BRDF lobe：查表取得线性变换，将多边形光源转换后，对余弦分布做解析积分近似。

通常还要估计 Fresnel 等剩余项。其质量依赖拟合、LUT 分辨率和材质；适合高效面积光源照明近似，不是任意 BRDF 的数学精确解析解。见[Eric Heitz：LTC 研究](https://eheitzresearch.wordpress.com/415-2/)。

### 19. 非真实感渲染怎样选择轮廓与着色方法？

背面膨胀法通过反转剔除并沿法线外扩形成轮廓，适合简洁实体外轮廓，但厚度、尖角和透视会影响线宽；后处理可从深度／法线／颜色差做边缘检测，但不能总区分语义轮廓与材质细节。

硬色阶、光照量化、笔触纹理、色调图和轮廓线应基于艺术目标选择。TAM 可为不同亮度区域准备笔触密度变化，避免把真实感光照公式当唯一目标。复杂线稿可能还需几何边分类、特征线或对象 ID。

### 20. 次表面散射与参与介质为什么不能只用 BRDF？

BRDF 假设入射与出射发生在同一表面位置。皮肤、蜡、牛奶等光进入材质内部后在另一位置散出，需要 BSSRDF 或屏幕空间／随机游走等近似。

雾、云、烟等参与介质还要沿光线积分吸收、外散射和内散射，常用 ray marching、解析相函数或专门采样。步长、阴影、相函数和时间噪声会影响质量；“所有体积只要后处理乘 alpha”无法描述体积传输。

头发、布料、纤维和薄膜也有专门散射或波动效应模型。效果所需细节、计算预算与数据可用性共同决定选型。

## 四、材质外观与色彩

### 21. 金属度、基础色与 sRGB 编码如何配合？

材质基础色是表面反射参数，不是直接显示到屏幕的 RGB；光照通常应在线性工作值下与 BRDF 运算。Base Color 贴图为颜色内容时通常需要正确 sRGB 解码，Normal、Roughness、Metallic、Mask 等数据纹理则通常按数据读取。

Metallic 的具体通道、纹理打包和默认转换由引擎工作流定义。贴图导入、采样器与 Render Target 的 sRGB 设置必须一致，否则会重复解码或漏解码。曝光／色调映射发生在场景光照之后，不能先对每个灯的编码颜色做显示曲线再相加。

### 22. 色调映射、曝光与颜色空间有什么区别？

曝光对线性场景值施加比例变化；Tone Mapping 将高动态范围映射到输出亮度范围；Gamut Mapping 处理输出色域外颜色；编码传递函数把线性输出转成显示／存储编码。它们解决不同问题。

ACES 是一套色彩管理与变换生态的名称，游戏中常见的 ACES Filmic 曲线只是相关色调映射实现／拟合之一。HDR 显示的输出也不必先压到传统 LDR，须按 SDR／HDR 目标配置 tone curve、色域和传递函数。

## 五、后处理

### 23. Bloom 如何避免变成整屏模糊？

Bloom 模拟强光在成像系统中的扩散：从 HDR 图像抽取高亮部分，逐级下采样／模糊形成宽范围低频，再与原始场景合成。阈值、高亮曲线、强度和多尺度核控制观感。

在线性 HDR 域分离能量更清晰；直接模糊全画面会使暗部发灰。Bloom 会让高亮溢出边界，需避免在已经 tone-map 的 LDR 上无条件扩散，否则亮度和颜色层次容易丢失。

### 24. 景深与运动模糊是两种什么样的积分？

景深来自有限光圈：像点不在焦平面时投成弥散圆。景深后处理从 CoC（Circle of Confusion）估计模糊范围，须处理近景与远景的遮挡、前景漏色和半径变化；只按深度模糊会把焦点边缘涂脏。

运动模糊是曝光时间内位置变化的时间积分。后处理方案常用 velocity buffer 沿运动方向取样近似；相机向量无法完整表示粒子、变形、旋转或反射运动，还需处理遮挡与速度不连续。

二者都可由路径采样中的光圈／时间采样获得，但实时后处理重建的是近似，参数应结合 shutter、焦距与运动速度解释。

### 25. 体积光、镜头光晕与调色应怎样放进管线？

体积光／雾会依介质密度和光源可见性沿视线积累，可用 froxel 网格、分段 ray marching 等方式；须控制步长、光源阴影、时间抖动和历史复用。屏幕空间体积效果无法完整恢复屏幕外介质信息。

镜头光晕常基于高亮提取与镜头特征近似，具有明显艺术属性。调色、白平衡、曝光、局部对比和 LUT 在合适的场景线性／显示参照下执行；必须知道该级输入是线性 HDR 还是显示编码，避免重复 Gamma／Tone Map。

## 六、光传输与外观补充

### 26. BDPT、MLT、光子映射、Instant Radiosity 与 VCM 有何区别？

| 方法 | 主要思想 | 典型取舍 |
| --- | --- | --- |
| BDPT 双向路径追踪 | 从光源和相机生成子路径，再组合连接并加权 | 可改善部分间接路径采样，连接／MIS 更复杂 |
| MLT 大都会光传输 | 对已有路径作马尔可夫扰动，偏向高贡献路径 | 适合某些困难光路；相关样本、初始化与收敛不均需处理 |
| 光子映射 | 从光源发射光子，利用邻域密度估计入射贡献 | 擅长部分焦散，有限半径有平滑偏差 |
| Instant Radiosity | 用采样路径产生虚拟点光源近似间接照明 | VPL 数量、奇异值、夹值和遮挡成本 |
| VCM | 结合顶点连接与密度合并 | 覆盖更多路径，估计与权重实现复杂 |

光子密度估计在适当样本／半径收敛条件下可一致，不代表任何固定半径或夹值方案都无偏。MLT 的“无偏”还需说明稳态、归一化估计和有限运行条件；Instant Radiosity 的截断、采样和 clamp 也影响偏差，不能只按算法名统一贴标签。参考：[Veach：蒙特卡洛光传输论文](https://graphics.stanford.edu/papers/veach_thesis/)。

### 27. Disney Principled BRDF 怎样面向艺术家？

以 Base Color、Metallic、Roughness、Anisotropy、Sheen、Clearcoat 等直观外观参数，组合不同散射 lobe，目标是在制作便利与物理合理性之间取舍。不同版本及引擎衍生模型的参数范围、默认值与归一化不完全相同。

Clearcoat 表示额外介质层，应处理它对底层能量的影响；Sheen 近似某些纤维掠射外观。不是所有参数一定在 0–1，也不是任意组合天然严格物理精确；金属度工作流相似不意味着 Unity、Unreal 或其他引擎使用完全相同的 Disney 公式。

### 28. 各向异性、头发、布料与薄膜为何要专门模型？

拉丝表面在不同切线方向有不同粗糙度，需要方向性 NDF 和稳定切线基。头发的反射、透射与内部反射可用 Marschner 等纤维模型描述，不能仅以各向同性球形高光替代；布料的纤维朝向、遮蔽和 sheen 也有专门近似。

肥皂泡和薄膜的颜色与厚度、角度、波长有关，干涉／衍射属于波动光学效应。普通 RGB 几何光学模型可做外观近似，精确预测通常要加入光谱与相位相关模型；“只换一张彩色纹理”不能解释随视角变化的规律。

## 高频答题模板

介绍算法时可依次说明：它要解决的瓶颈 → 数学／数据表示 → 每帧或离线步骤 → 画质与性能优势 → 失败模式和适用边界。比较技术时指出它们使用了哪些信息、舍弃了什么，以及成本落在哪个阶段。
