## 一、渲染方程与光线追踪

### 1. 什么是渲染方程？各项表示什么？

**答案：**

渲染方程描述某点沿观察方向的出射光：**自身发光，加上所有方向入射光经材质反射后的贡献**。

```text
Lo(p, V) = Le(p, V) + ∫Ω fr(p, L, V) Li(p, L) max(N·L, 0) dω
```

- Lo：出射辐亮度；Le：自发光。
- Li：从方向 L 到达表面的入射辐亮度。
- fr：材质的 BRDF，描述入射到出射方向的反射关系。
- N·L：入射投影面积的余弦权重；dω 为立体角微元。

入射光又可能来自其他表面的反射，因此求解包含全局光照。IBL、Lightmap、路径追踪分别通过预计算或采样近似这一积分。

### 2. BRDF 是什么？有哪些基本性质？

**答案：**

BRDF 描述光从一个方向入射后，向另一个方向反射的分布，是出射辐亮度对入射辐照度的比率，单位为 sr⁻¹。

常见物理反射模型要求非负、能量不增，并在互易介质中满足入射／出射方向交换的互易性。Lambert BRDF 是常数 `albedo/π`；镜面和粗糙表面则强烈依赖方向。反射能量受半球积分约束，不要求每个方向的 BRDF 数值都小于 1。

### 3. Whitted 光线追踪的步骤和缺点是什么？

**答案：**

从相机发射主光线找最近交点，交点朝光源发阴影射线，再沿理想反射／折射方向递归追踪，累加各项贡献。

它能实现硬阴影、镜面反射和折射；经典形式不采样漫反射的随机反弹，因此不能完整表现颜色渗出和粗糙间接光。递归成本需要通过深度或终止条件控制。

### 4. 路径追踪的原理和实现步骤是什么？

**答案：**

路径追踪通过随机光路估计渲染方程，表面每次按材质分布采样下一方向，并将贡献按采样概率加权。

1. 相机向像素发射射线，求最近交点。
2. 累积命中表面的发光；未命中时累积环境光。
3. 根据 BSDF 采样新方向，更新路径权重 `beta *= f × abs(N·L) / pdf`。
4. 从交点继续追踪，直到路径终止。
5. 多条路径结果平均得到像素颜色。

优点是统一处理多次间接反射；缺点是低样本时噪声明显，求交和材质计算成本高。实际通常加入直接光源采样和 MIS 来减少方差。

### 5. 蒙特卡洛积分为什么需要除以 PDF？

**答案：**

以分布 p(x) 采样时，积分估计为 `I ≈ (1/N)Σ f(Xi)/p(Xi)`。高概率区域被采到更多次，除以概率密度能补偿这种偏向，使期望等于目标积分。

重要性采样让 p 接近贡献分布，可减少方差；但凡有贡献的区域都必须有合适的采样覆盖。常见独立样本估计的误差按约 `1/√N` 下降，要将误差减半通常需约四倍样本。

### 6. 俄罗斯轮盘赌如何终止路径并保持无偏？

**答案：**

为路径设置存活概率 q：以 1−q 的概率终止，存活时将后续路径权重除以 q，补偿被丢弃路径的期望贡献。

```text
if random() >= q: terminate
else: beta /= q
```

q 可随路径能量调整，通常先保留若干次反弹再使用。RR 节省长路径成本，会增加方差；若描述的是终止概率 p，补偿分母应为 1−p。

### 7. 什么是直接光源采样和 MIS？

**答案：**

直接光源采样在表面主动选一个光源位置，发射可见性射线，估计直接照明，避免随机 BSDF 射线很难命中小光源。

MIS 将光源采样与 BSDF 采样按相应 PDF 加权：小光源时前者更有效，窄高光时后者可能更有效。两者组合可降低极端样本和噪声；面积 PDF 转方向 PDF 时还需距离和余弦换算。

### 8. 光线追踪为什么需要 BVH？

**答案：**

暴力求交要逐个检查场景图元。BVH 将图元组织为层次包围盒，射线不碰某个盒子时即可跳过整组图元，命中后才继续向下遍历。

构建常用 SAH 等代价估计；动态场景可 refit 或重建。优势是大量减少求交，代价是构建、存储和更新。层级重叠或形变过大时效率会降低。

## 二、Vulkan 光追

### 9. Vulkan 光线追踪管线有哪些阶段？

**答案：**

Ray Generation 生成射线并发起追踪；实现遍历加速结构，普通三角形使用内建求交，程序化几何由 Intersection Shader 报告交点。

Any Hit 可过滤候选交点，如 Alpha Clip；确定有效最近命中后由 Closest Hit 着色，无有效命中时执行 Miss。Callable 是显式调用的着色程序。Closest Hit 与 Miss 是不同结果分支，不会每条射线都顺序执行一遍。

常用能力包括 acceleration_structure、ray_tracing_pipeline 和 ray_query，设备须支持并启用相应特性。

### 10. BLAS 和 TLAS 有什么区别？动态场景如何更新？

**答案：**

BLAS 表示模型几何集合，输入常为三角形或 AABB；TLAS 保存 BLAS 实例引用、变换和实例数据，同一 BLAS 可多次实例化。

仅刚体实例变换改变时，通常更新 TLAS；蒙皮或顶点变形需要更新／重建 BLAS。update 须满足最初构建标志与结构限制。静态几何可偏向 FAST_TRACE，高频重建可考虑 FAST_BUILD，取舍是构建时间与遍历效率。

### 11. SBT 是什么？如何把材质与命中着色器关联？

**答案：**

SBT（Shader Binding Table）保存着色器组 handle 及应用数据。发射射线时提供 raygen、miss、hit 等区域；命中时结合实例和几何的 record offset 选择相应命中组。

命中组可以组合 closest hit、any hit 和程序化求交阶段。SBT 地址、stride 和 record 对齐须满足设备要求；材质参数可在 record 或描述符指向的 buffer 中索引。

### 12. Vulkan 一次光追如何执行？Ray Query 有什么区别？

**答案：**

准备几何和实例 → 构建／更新 AS → 准备 RT pipeline、描述符和 SBT → 调用 trace rays → 降噪并与其他渲染结果合成。AS 构建写入到追踪读取之间需正确同步。

Ray Query 允许在普通图形／Compute Shader 中显式查询 AS，适合局部阴影、反射测试等；独立 RT pipeline 用专用阶段组织工作。递归深度受设备限制，也可用迭代循环管理反弹。

## 三、PBR 与材质

### 13. 什么是 PBR？常用材质参数有哪些？

**答案：**

PBR 以物理规律为依据描述材质与光照，常结合能量约束、微表面模型和线性光照计算，使材质在不同环境下表现更一致。

常用参数包括 Base Color、Metallic、Roughness、Normal、AO 和 Emission。金属度控制金属／电介质工作流，粗糙度控制高光分布；法线、粗糙度等数据贴图通常不做 sRGB 解码。

### 14. 微表面 BRDF 中 D、F、G 分别是什么？

**答案：**

粗糙表面可视为大量微小镜面，只有朝向合适的微面把入射光反射到眼睛。常见 Cook–Torrance 形式为：

```text
h = normalize(L + V)
fs = D(h) × F(V,h) × G(L,V) / [4(N·L)(N·V)]
```

D 是法线分布，控制高光形状；F 是 Fresnel，控制随角度变化的反射率；G 是微面自遮挡与掩蔽。正面光照中使用该式，并处理掠射数值问题。GGX 具有较长高光尾部，是常用 NDF。

### 15. Fresnel 效应是什么？金属与非金属有什么区别？

**答案：**

反射率随角度变化，掠射时通常更强。Schlick 近似为 `F=F0+(1−F0)(1−V·H)^5`，F0 是正入射反射率。

常见电介质的 F0 较低、镜面接近无色，基础色主要影响漫反射；金属镜面反射通常有色，金属工作流一般去掉普通漫反射，并以基础色控制镜面颜色。

### 16. 粗糙度有什么作用？为什么需要多次散射能量补偿？

**答案：**

粗糙度增大使微面朝向更分散，高光更宽、峰值降低，环境反射更模糊。

单次散射微表面模型会漏算被遮挡后多次反射再逸出的能量，粗糙表面可能偏暗。Kulla–Conty 等方法用预计算表或近似补回多次散射贡献，须与原 BRDF 能量计算匹配。

### 17. Disney Principled BRDF 的设计思路是什么？

**答案：**

用 Base Color、Metallic、Roughness、Anisotropy、Sheen、Clearcoat 等直观参数组合散射波瓣，降低艺术家调材质的难度，让一个模型覆盖较多常见外观。

它以物理合理性指导工程设计，但具体版本和引擎实现不同。清漆是额外表层，需要考虑对底层能量的影响；各向异性用于拉丝等有明显方向的表面。

### 18. LTC 如何计算面光源照明？

**答案：**

LTC 用线性变换后的余弦分布拟合 BRDF 波瓣，将多边形光源按对应逆变换处理，再利用余弦分布的解析积分求近似照明。

变换参数按粗糙度和 N·V 预计算到 LUT，运行时查表。优点是较低成本计算矩形等多边形面光源；缺点是拟合误差，遮挡／阴影还需另外求解。

### 19. 次表面散射怎么实现？

**答案：**

次表面散射指光进入材质内部，在其他位置散出，常见于皮肤、蜡和玉石。

实时方案可对漫反射照明按散射轮廓做屏幕空间模糊，结合深度／法线避免跨物体；更完整的方案用 BSSRDF 或内部随机游走。优点是表现柔和透光和颜色扩散；屏幕方案在轮廓、遮挡和厚度变化处误差较大。

### 20. 体积雾和体积光怎么实现？

**答案：**

沿视线在介质中采样，根据密度累计透射率，并计算每个位置被光源照亮后向视线散射的贡献。光源阴影决定哪些体积位置受光，可形成光束。

常用低分辨率 ray marching 或 froxel 网格，配合抖动和时间重建控制成本。步数少会分层，历史复用可能拖影；介质相函数控制前向／后向散射特点。

### 21. 卡通渲染和描边常用什么方法？

**答案：**

卡通着色常把光照量化成几档色块，结合 ramp 纹理、艺术化阴影和手绘贴图。

描边可用背面膨胀形成轮廓，或对屏幕深度／法线做边缘检测。前者适合实体轮廓，但尖角和缩放影响线宽；后者容易实现统一屏幕线宽，但会受可见图像和边缘阈值限制。

## 四、后处理与高级光传输

### 22. Bloom 怎么实现？

**答案：**

从 HDR 图像提取或加权高亮 → 多尺度下采样和模糊 → 上采样叠加 → 与场景合成。

它近似强光在成像系统中的扩散，使亮部溢出到邻近区域。阈值、核尺度和强度控制效果；过强会发灰、丢细节，通常在色调映射前利用 HDR 亮度处理。

### 23. 景深怎么实现？

**答案：**

根据焦距、光圈、焦平面和像素深度估计弥散圆 CoC，再以 CoC 控制模糊半径，分别处理前景和背景后合成。

离焦越远、光圈越大，模糊通常越明显。实时屏幕方案成本可控，但前景边缘可能漏色或缺背景信息；光追方案可直接采样镜头光圈位置得到更完整的景深。

### 24. 运动模糊怎么实现？

**答案：**

运动模糊来自曝光时间内运动的积分。实时方法根据相机和对象上一帧位置生成速度缓冲，沿速度方向采样并合成颜色。

采样范围与快门时间和速度有关；深度边界需防止前后景混色。蒙皮、粒子、透明和反射可能需要额外运动信息。光追可通过快门时间采样直接模拟。

### 25. BDPT、MLT 和光子映射分别解决什么问题？

**答案：**

BDPT 同时从相机和光源生成子路径，再连接并加权，改善某些难以由单向路径采到的光路。

MLT 在路径空间扰动已有路径，将采样集中到高贡献区域，适合部分狭窄通道等困难光路，但样本相关、收敛不均。

光子映射从光源发射并记录光子，着色时做邻域密度估计，适合焦散；有限半径会平滑细节并产生偏差。VCM 结合路径连接与顶点合并。
